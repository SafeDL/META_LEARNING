# Confirmation protocol notes

The manifest, release profiles, endpoint, 20+20 query budget, method set,
and selector ranking logic were frozen before confirmation target outcomes were
read. During the physical run, evaluator output was extended with context
summaries, 4/8-neighbor region coverage, plots, and stricter cache checks.
These reporting changes do not alter the frozen candidate pools or query order.

The confirmation resolution is 7×7 for each of three predefined contexts in
each of three scenario families (441 concrete scenes). It was fixed before
the paired full bank was measured. The development run has a separate 5×5
grid and one different context per family; the two runs are not pooled as
independent physical replicates.
