# 目标适配特征的局部可靠性：历史诊断

目前收敛推断的历史结果中，原参数距离的局部权重仍未胜过全局控制。另行检查目标反馈形成的表示是否更适合界定来源适用区域。该诊断只使用历史系统，不改变[已登记160项搜索](collision_discovery_converged_inference.md)、任何强基线或既有失败结论。

保留原16个历史任务、种子1301的128点有序支持集、不相交32点查询集，以及129个已保存的CUDA目标适配状态。自身来源后验从上下文排除；基础教师仍见过全部历史对象，本项不是严格留系统验证。条件推断使用已核对的收敛求解，两个场景均固定β=1；物理概率沿用同一缓存，隔离可靠性距离的作用。不新增网络训练、开发选例、物理执行或轨迹权限。

记原历史初始化特征为φ₀，已付费t个标签后的特征为φₜ。用原历史512个公开坐标上φ₀的均方偏差得到一个固定标量τ²。比较原归一化参数距离、φ₀距离和φₜ距离；特征距离为`mean((φ(x)−φ(x′))²)/τ²`。使用同一个固定尺度，避免逐维缩放改变深核原有的旋转对称性。带宽只比较0.15、0.30、0.60，另保留κ=1的全局控制，共10个配置。

在每个支持规模t，适配距离版本重新计算

\[
\log w_{s,t}(x)=\log\pi_s+
\sum_{i<t}\exp\!\left[-\frac{d_t(x,x_i)}{2\ell^2}\right]
\log P_s(y_i\mid\mathcal D_{i-1})-\log Z_t(x).
\]

保存的每条对数似然来自当时查询前的预测，之后不重新评分。φₜ只由已经付费的标签形成，不能使用未查询标签或查询集结果。目标独立分量参与同一规则，来源/独立目标先验质量仍为0.75/0.25，外层物理质量为0.10。这里检验可靠性区域，不单独把特征距离或局部加权作为原创贡献。

在8、16、32、64、128支持处记录NLL与Brier，共`16×10×5=800`项评分。按历史谱系等权汇总；为每种距离分别在其余历史谱系上按NLL、Brier、较大带宽选取配置，再报告留出谱系的损失。仅当适配特征在两个场景都比全局、选中的参数距离及固定特征距离有更低NLL、Brier不升，且各比较至少两个历史谱系获得NLL正收益，才支持另行登记后续在线比较。即使满足，也不代表128次碰撞发现门槛通过；不满足时保留完整结果，不追加在线矩阵。

先验证空反馈返回先验、κ=1与全局累计一致、来源排列不变、特征刚性变换及统一尺度变换不改变距离，以及重复或多余的反馈记录被拒绝。独立NumPy/SciPy检查64组分量概率、800组权重/混合概率，并与既有收敛历史结果核对160项全局/原参数控制。保留全部零碰撞历史任务、完整配置及成本。

入口为`python -B -m benchmark.discovery_feature_reliability prepare`、`run`。输出在`results/benchmark/collision/discovery/feature_reliability/`，包括协议、16项历史JSON/NPZ、固定尺度参考、独立数值检查、全部评分、带宽选择和报告。数值或缓存核对失败即停止并保存错误，不改旧输入、容差或先验。C/D/E状态保持原样。

## 已完成结果

19项相关检查通过；全部16任务、800项评分和16,384次非空模式求解完成，最终梯度均不超过1e-10。64组独立分量预测最大差1.70e-11，800组独立权重/混合概率最大差分别7.44e-15和5.56e-15；160项既有收敛控制评分复现差不超过5.56e-16。另从保存数组重算800组权重与评分、64项查询前似然检查点、48次留谱系带宽选择及64项留谱系结果，均通过，见`summary_audit.json`。诊断耗时68.90秒，没有新增开发查询或物理执行。
