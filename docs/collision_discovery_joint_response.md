# 碰撞与安全响应联合后验的后续验证

## 1. 依据、目标与不变条件

本文件补充[原执行方案](collision_discovery_plan.md)和[后续开发协议](collision_discovery_recovery.md)，不覆盖任何旧协议与失败结果。目标仍是在128次付费查询内发现更多真实碰撞、提高完整候选库碰撞召回。50%剩余漏检减少、数量不降低、至少两个谱系正收益的门槛保持不变；新强对照参与最强基线选择。C/D/E继续受开发准入控制。

已有诊断表明：增加历史碰撞/安全响应坐标、改善响应预测、强化目标独立分量，均未获得足够发现收益。最新200项强目标实验中，主方法平均36.450个碰撞、95.464674%召回，仍低于96.051630%的物理特征对照。下一步不继续搜索相同融合权重。

拟验证的解释是：只用碰撞/未碰撞更新来源可靠性，可能难以区分多个都预测安全、但响应差异很大的历史系统。同一次测试已返回最小间距；它可能帮助识别来源适用区域并学习碰撞边界。这个解释是待验证假设，不能由已有负结果直接认定。

仍使用8个历史系统、4个开发系统，切入和切出每任务512候选；共同初始化8次计入128次预算；选例种子11、23、37、53、71，环境种子81001。首个比较只复用已有记录，新增物理调用为零。旧最终对象和新正式对象均不参与选参。

## 2. 两类真实观测分别保留

完整48份历史/开发档案共有24,576份响应。检查发现：非碰撞样本的最小间距均为正，但181份碰撞响应的保存最小间距也大于零；其中切入75份、切出38份。记录位于`results/benchmark/collision/discovery/margin_observation/report.json`。

本地HighwayEnv的`handle_collisions`和`Vehicle.step`会处理预期碰撞的`impact`并更新位置及碰撞标记。离散记录中的多边形距离与碰撞标记因此不能简单等同；这与上述观察一致，不能仅凭正间距认定标签错误。本轮保持原碰撞定义和执行档案。

每次付费查询保留两个观测：实际布尔碰撞标记`c`，以及同次反馈的最小间距`d`。碰撞数量和召回率始终只使用`c`。间距采用固定变换

\[
z=\frac{\log(1+\min(d,100\ \mathrm m))}{\log 11}.
\]

无穷大间距映射到100m上限；不据此产生碰撞或安全标签。首个原型不使用在线TTC，也不增加轨迹访问权限，不修改`QueryFeedback`。这是相对前几轮“在线只使用碰撞标签”的显式信息变化，必须通过同信息强对照分析。

## 3. 联合模型与后验传递

用两个潜变量分别表示碰撞倾向`f_c(x)`与变换间距`f_z(x)`：

\[
c\sim\operatorname{Bernoulli}(\sigma(f_c)),\qquad
z\sim\mathcal N(f_z,0.05^2).
\]

它们的关系由联合GP学习，不设定“间距等于零当且仅当碰撞”。初始核采用与FSBO相同的4层32维深核，额外增加两个通道的均值、尺度和相关参数，不增大隐藏网络：

\[
K_{\mathrm{joint}}(x,x')=
\begin{bmatrix}1&\rho a\\ \rho a&a^2\end{bmatrix}
k_\theta(x,x'),\qquad a>0,\ |\rho|<1.
\]

相关参数以`tanh`参数化，初始ρ=-0.5、a=0.3；碰撞潜均值初始-1.4，间距潜均值0.5。先对已查询的间距作解析高斯条件化，再对实际碰撞标签作10轮Laplace近似；不将间距转换成伪碰撞标签。

从每个历史系统的512份真实响应计算联合高斯近似后验`(μ_s,C_s)`。对公开候选坐标预测的均值与协方差只依赖历史标签，存为来源预测缓存；缓存不包含目标标签。目标来源分量采用

\[
m_{s,t}=\mu_s+(m_t-m_{\mathrm{meta}}),\qquad
K_{s,t}=K_t+C_s.
\]

其中`K_t,m_t`是每轮由全部已付费反馈适配的目标核与均值，额外独立目标分量为`(m_t,K_t)`。历史协方差表达历史响应的不确定性，残差核允许目标系统偏离历史。无历史均值偏移且`C_s=0`时，该分量应恢复目标独立模型。

来源初始总质量0.75，目标独立分量0.25；历史来源按现有家族权重分配。局部可靠性仍采用归一化场景特征均方距离、带宽0.30，全局对照κ=1。

完整反馈的预测似然按链式法则计算：

\[
P(z_i,c_i\mid\mathcal D_{i-1})=
p(z_i\mid\mathcal D_{i-1})
P(c_i\mid z_i,\mathcal D_{i-1}).
\]

条件碰撞概率可使用本次新间距，但不得使用本次碰撞标签拟合后的状态；两项均从查询前联合分布计算。更新来源权重后再重建真实后验。查询前选例仍使用尚未看到本次间距时的无条件碰撞概率。该组合使用近似GP后验，不预先承诺概率校准。

## 4. 从历史档案开始训练

训练相关和ρ=0两个基础模型，各覆盖切入/切出，共4个模型。ρ=0对照固定相关参数，其余网络、历史数据、优化预算和初始化相同。

- 随机初始化种子1301，不把旧检查点作为方法定义。
- 1500次更新，Adam学习率0.001，梯度范数上限5。
- 每步等概率选择历史系统，再从8、16、32、64、128中选择批大小；不按碰撞标签过采样。
- 损失为同批间距的高斯边缘似然，加给定这些间距后的碰撞Laplace证据，按批大小归一化。
- 每100步验证，使用开发系统、支持集8/16/32/64/128、固定种子1319及32个查询点。支持集合嵌套，查询点与全部支持点分离；每个开发系统5种支持集，每次验证共20项。
- 每项开发验证先从当前基础模型出发，用支持集真实反馈适配10步、学习率0.003；查询点间距不能用于预测。
- 仅以开发查询集碰撞NLL选择检查点，谱系等权。间距预测损失单独报告，不替代碰撞目标。

训练数据来源、开发来源、参数、检查点、角色和档案指纹全部登记。严格留家族构建时，基础训练、来源后验与开发选参均排除留出家族。独立阶段需重新训练与最终方法一致的模型。

## 5. 首个冻结比较：280项运行

| 方法 | 作用 |
|---|---|
| `joint_local`：主方法 | 来源独立联合后验，局部可靠性，在线使用碰撞和间距 |
| `joint_global` | 同一预测器，κ=1，隔离局部可靠性 |
| `joint_shared` | 来源保留各自均值，共用历史协方差的家族等权平均，隔离来源协方差 |
| `joint_mean` | 仅传递来源均值，C_s=0，检查完整后验是否有额外价值 |
| `joint_binary` | 相同历史联合后验，在线只用碰撞标签，隔离新增在线信息 |
| `joint_target` | 同一相关基础模型，仅用目标付费反馈，不使用历史来源后验 |
| `joint_uncorrelated` | ρ=0基础模型，仅用目标反馈，保留共享表示及间距辅助拟合 |

每方法40项，共280项、35,840次等效查询。两个仅目标联合模型与现有最强基线共同参与参考选择，不能只对旧二值FSBO计算漏检减少。

主要准入仍为50%漏检减少、数量不降低、至少两个谱系正收益。局部来源机制还须优于全局对照。来源协方差、跨响应相关与在线间距各自的结论由对应消融决定；不能把新增信息或一般多任务学习全部解释为历史后验贡献。若完整协方差未改善发现，则不把它保留为最终贡献。

正式扩展前按开发证据确定最终结构，冻结后再做独立目标验证。原旧场景及新交互任务、八条新目标路线和严格留家族范围不缩减。

## 7. 已有方法边界

多输出GP的核设计已有系统论述，不能把二维相关核本身作为原创贡献。[Kernels for Vector-Valued Functions: a Review](https://arxiv.org/abs/1106.6251)

利用来源GP后验进行任务迁移也已有研究，本轮待验证的是联合碰撞/安全响应的后验是否在相同付费反馈、强目标模型和局部机制对照下改善真实碰撞发现。[Transfer Learning with Gaussian Processes for Bayesian Optimization](https://proceedings.mlr.press/v151/tighineanu22a.html)
