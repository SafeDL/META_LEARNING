# 历史后验与独立物理分量的开发验证

## 依据与范围

本方案延续[原执行方案](collision_discovery_plan.md)及用户确认的[128次预算后续协议](collision_discovery_recovery.md)。原方案、此前失败和完整消融均保留；本方案不把旧准入改成通过。研究目标仍是提高真实去重碰撞数量和全候选库召回，后续C/D/E的场景、独立目标、留家族与成本范围不缩减。

[文献定位与证据要求](collision_discovery_method_positioning.md)对应共享深核、来源GP集成、层次GP后验迁移、ENS和历史失效测试。单来源均值及协方差先验采用已有层次GP基础，当前验证重点是同信息条件下的跨控制器响应收益；正式方法定型须说明与最接近方法的差异。

[联合响应实验](collision_discovery_joint_response.md)已完成的结构消融显示：局部权重没有超过全局；完整历史协方差相对仅均值的额外召回很小，区间跨零；仅使用碰撞标签的版本召回97.422184%，与在线同时使用碰撞和间距的主方法97.399457%接近。完整280项及两个同反馈目标模型均已完成并独立复核，原主方法未通过门槛。

相同127次付费前缀的120项预测诊断表明，原始物理特征GP能把PPO切出一项漏检从深核的剩余排名286至368提高到4至34，但其全剩余库NLL/Brier明显更差。因此下一步检验物理分量的互补，不整体替换历史模型，也不把排名改善当作实际发现。该诊断未增加查询或物理调用。

本次主配置预先指定为全局可靠性、在线仅使用真实碰撞。局部可靠性与在线间距保留为消融，不再强求它们成为最终贡献。这个变化只适用于新的开发方案，不改变前轮主方法及其失败结论。

## 方法定义

历史侧复用已从历史档案训练的联合模型，以及每个来源的碰撞/间距联合后验。主方法在线仅使用其碰撞潜变量边缘：来源均值为`μ_s^c+(m_t-m_H)`，核为`K_t+C_s^cc`。独立深核目标分量为`m_t,K_t`。来源后验只来自历史系统，目标标签只能来自已付费查询。

历史来源初始总质量0.75，独立深核目标分量0.25；来源按既有家族权重分配。它们组成联合模型组，组内用查询前碰撞概率的二值对数得分更新全局可靠性。每次真实查询后，深核从同一历史初始化出发，对全部已付费碰撞标签拟合10步，学习率0.003。主方法不使用在线间距或TTC拟合，也不使用它们评分来源。

额外物理目标GP始终使用原始归一化场景特征、原Matérn分类核和3个标量参数，不使用历史表示或历史标签。初始均值0、尺度1、长度尺度0.3；每次查询后从该常量初始化出发，对同一批已付费碰撞标签拟合10步，学习率0.01。

主方法固定使用

\[
p_t(x)=0.90\,p_{\mathrm{joint},t}(x)+0.10\,p_{\mathrm{physical},t}(x).
\]

物理分量不参与组内来源可靠性更新，0.10在运行前固定，不按本轮收益搜索。有效初始质量为历史0.675、独立深核0.225、独立物理0.10。固定质量使物理分量不会因早期安全反馈完全消失；`p_t(x)≥0.10 p_physical,t(x)`只是模型输出的代数关系，不是对真实碰撞率、校准或覆盖的保证。

仍按最终混合碰撞概率贪心选例。所有得分必须来自当前反馈到达前的状态；反馈后先更新可靠性，再重新适配两个目标核。候选已查询后移出待选集合。首轮不加入前瞻、额外驾驶系统、网络扩容或新仿真。

## 320项冻结比较

仍使用8个历史、4个开发系统；切入/切出各512候选；共同初始化8次计入128次预算；选例种子11、23、37、53、71，环境种子81001。每方法40项，共320项、40,960次等效查询；全部复用已有执行库，新增物理调用为零。批量顺序先运行三个新增强对照，再运行主方法及其余消融；不根据对照胜负删改方法。

| 方法 | 固定差异 |
|---|---|
| `physical_global`，主方法 | 全局来源可靠性，保留0.10物理质量，在线只用碰撞 |
| `physical_local` | 仅将来源可靠性改为局部，高斯带宽0.30；物理质量不变 |
| `physical_mean` | 全局权重，仅传递各来源均值，历史协方差置零 |
| `physical_target` | 同一历史训练深核加相同物理GP，不提供历史来源后验 |
| `physical_adaptive` | 同一初始0.90/0.10；两组质量随后按查询前二值对数得分作全局更新，不固定保留质量 |
| `physical_margin` | 只在联合模型组加入在线间距条件化和完整联合似然，其余保持全局固定质量 |
| `physical_fsbo` | 原FSBO历史初始化与原分类GP适配/预测，加同一0.10物理GP，无来源后验 |
| `fsbo_cuda` | 原FSBO权重、10步/0.003适配与贪心预测，在同一CUDA设备运行，不添加物理GP |

`physical_margin`的物理GP仍只用碰撞；固定外层质量不比较连续密度与二值概率。`physical_adaptive`的两个组均只用查询前二值得分，避免把不同观测维度的似然直接比较。

强基线集合包含原四个强基线、相对运动核、两个旧目标融合对照、全部7个联合响应版本，以及本轮`physical_target`、`physical_fsbo`和`fsbo_cuda`。后两个对照同时检查普通FSBO混合与计算后端影响：既有原FSBO使用CPU，而已冻结的联合模型运行于CUDA；相同参数下CPU/CUDA适配轨迹可能存在数值差异，不能将其全部归因于方法。新CUDA入口直接复用原分类核、适配和概率函数，CPU入口对照与原实现逐次一致，另在CUDA和独立NumPy中验证。

因此此前更好的全局版本也参与参考选择，不能退回只对较弱的旧FSBO或物理特征基线计算漏检减少。复用对照必须保留全部40项配对候选、种子和128预算；任何缺项拒绝验收。

## 准入与解释

主方法须同时满足：相对该集合中平均召回最高者减少至少50%的剩余漏检；碰撞数量不降低；至少两个有碰撞谱系召回正收益；相对同初始质量的`physical_adaptive`召回更高、数量不降低。最后一项检验保留质量是否比一般可靠性融合有效。

局部权重、完整历史协方差和在线间距各自由对应消融说明，不把它们预先列为成立的贡献。辅助版本更好时不自动替换主方法并宣称原门槛通过。一般模型混合、多输出GP和全局得分加权本身不作为独立原创主张；研究价值须由相同付费信息下的来源后验对照及后续独立系统结果支撑。

基线全召回时漏检减少比例不适用，不能平滑成成功；全库无碰撞任务数量记零、召回不适用，保留任务与成本。先在谱系内汇总，再对谱系等权，报告配对分层自助区间与16/32/64/128预算点及完整曲线。同库数量与召回不作为独立证据。

通过新的开发门槛后才能建立独立准入记录进入后续阶段。正式推断前仍须从历史档案重新训练与最终核、分量和可靠性机制一致的模型，支持规模8/16/32/64/128；严格留家族时训练、来源上下文与开发选参均排除留出家族。旧训练基础只用于本轮机制开发，不能直接写成正式构建完成。

## 接口、入口与输出

实现位于`methods/gcrt/physical_mixture.py`，复用冻结联合推断和已有分类GP，不修改旧协议覆盖的源码。`QueryFeedback`、执行账本及隔离查询保持原接口；选择器仅获得公开候选、历史预测和已付费反馈。两个核及局部距离统一使用公开候选特征映射；默认采用既有映射，后续新增交互任务可显式传入其冻结映射。

```powershell
python -B -m benchmark.discovery_physical_mixture freeze
python -B -m benchmark.discovery_physical_mixture smoke
python -B -m benchmark.discovery_physical_mixture_negative_controls
python -B -m benchmark.discovery_physical_mixture run
python -B -m benchmark.discovery_physical_mixture_audit available
python -B -m benchmark.discovery_physical_mixture audit
python -B -m benchmark.discovery_physical_mixture report
python -B -m benchmark.discovery_physical_mixture_report
```

`freeze`要求联合响应280项全部完成且独立复核通过，检查其准入重算一致，再冻结代码、模型、来源后验和已有结果身份。条件未满足时不建立新协议，不启动新矩阵。新运行保存于`results/gcrt/collision/discovery/physical_mixture/runs/`，协议、审计、门槛和JUnit保存于`results/benchmark/collision/discovery/physical_mixture/`。

`smoke`对同一开发任务运行全部8种方法，这8项属于完整矩阵，不额外扩大样本。损坏记录入口先独立重建这8项，再在内存中修改碰撞、间距、分母、权重、物理概率、来源似然、外层质量和账本用途，要求全部拒绝；原文件不修改。通过后再启动其余运行，已完成项按同一协议复用。

失败运行追加保存完整已付费账本、退出原因和成本，不覆盖先前失败。批量运行一项失败后取消尚未启动的项，保留已完成结果。已有记录只有在同一冻结协议下才复用。

`audit available`仅复核已完整保存的运行，不宣称整组通过。逐项证据绑定审计源码及数值依赖、冻结协议、运行文件和原始反馈的身份；发生变化时重新复核。已通过实际复用检查：50份原有证据未改写，另16项新运行通过。完整审计仍要求320项齐备。

`benchmark.discovery_physical_mixture_report`在完整320项独立审计通过后，生成数量/召回曲线PNG、SVG、PDF、预算点、配对区间和分项成本。每个预算点都从预登记强集合中选择该点最强参考，不只比较128次时的最强者；低预算结果不替换128次主门槛。已验证完整审计未完成时拒绝正式汇总，并用上一轮9个完整方法重建核对聚合曲线、检查零碰撞召回不适用及8种方法的计时字段。

### 相同付费前缀的漏检诊断

### 下一项同信息诊断：来源条件适配

当前原型在线拟合`fit_joint`的独立目标证据，预测时再叠加来源均值与协方差。下一项先检验这一适配选择，保持碰撞为唯一在线监督、模型宽度/深度及查询预算不变，再决定是否需要阶段反馈。

在现有主方法全部40项任务的第127次付费前缀上，比较两个因素：目标初始化为现有联合响应或FSBO；目标适配采用独立目标证据或加权来源条件证据。共160项预测配置，不启动新选例。条件先验使用`μ_s+(m_θ−m_init)`及`C_s+K_θ`，`m_init`为对应目标初始化的均值，保证更换目标初始化时来源均值没有额外平移。来源权重固定为原运行第128次查询前的可靠性，物理分量保持0.10。

来源条件目标为各分量Bernoulli GP的Laplace负对数证据按这些固定权重求和；这是一项适配目标的对照，不预先宣称为完整混合模型的精确证据。独立目标分量采用相同规则。两种目标均从同一初始化重置，适配10步、学习率0.003、梯度裁剪5。全部拟合只使用已付费的127个标签；剩余库标签只用于之后的误差和真实碰撞排名分析。

必须核对：独立目标、联合初始化配置恢复原主方法预测；无来源条件目标退化为现有目标GP；来源排列不影响结果；全零/全一标签和127支持点的损失、梯度与概率有限；概率由独立NumPy Gaussian/Laplace推断复核。汇总覆盖全部开发谱系及零碰撞任务，不只观察PPO两个关注点，也不以预测误差替代碰撞发现门槛。

该诊断入口和实现是后续工作，计划输出在独立的`conditional_adaptation/`目录。若进入新的在线验证，须待当前320项完成，先登记主配置与机制对照，并将本轮全部已完成方法纳入下一轮强参考；128预算、50%漏检减少、数量和谱系条件保持。当前主方法失败、阶段C/D/E状态不改写。

当前运行后已串接全量审计和完整报告生成。等待程序持有现有运行进程的句柄，进程退出后依次执行上述`audit`与完整报告入口；任一步非零退出即停止后续操作。运行状态、进程及命令记于`physical_mixture/watcher.json`。该队列只执行本轮验收，后续C/D/E仍须按门槛另行进入。

### 整组验收与条件适配诊断结果

320项现已全部完成，独立审计通过：核对40,960条付费反馈、35,840次两层可靠性更新，并独立重建960次完整候选选点。完整[开发报告](../results/benchmark/collision/discovery/physical_mixture/report.md)、预算16/32/64/128的最强参考与配对区间、PNG/SVG/PDF曲线及分项成本均已生成；PNG已目视检查。主方法五项门槛中漏检减少一项失败，其余四项满足，整组准入为未通过。在线间距消融平均37.850个碰撞、98.085227%召回、AUC24.673，没有改变这一结论。至此累计1,720项有效搜索、220,160次等效查询，失败尝试另列；本轮新增物理调用为零。C/D/E继续未进入。
