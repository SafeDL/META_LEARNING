# 逐来源响应特征的历史树模型筛选

## 假设与已有方法

收敛推断、核视图可靠性及百分位融合均未达到各自预定条件。本项不再改变这些权重规则，而检验模型表达：若来源的失效边界可通过少量参数阈值区分，保留逐来源响应作为树的输入，是否比相同静态历史先验下的物理特征或单一汇总响应更有利于发现。

树模型用于黑盒序贯优化已有[SMAC](https://www.cs.ubc.ca/~hutter/papers/10-TR-SMAC.pdf)等先例；从树分区构造核也已有[随机分区核](https://mlg.eng.cam.ac.uk/pub/pdf/DavGha14a.pdf)。本项使用[ExtraTreesClassifier](https://scikit-learn.org/1.7/modules/generated/sklearn.ensemble.ExtraTreesClassifier.html)作受控的表达筛选，不称为SMAC复现，也不把树、响应特征拼接或随机森林核单独列为新贡献。是否值得形成新方法，仍须机制及独立对象的完整证据。

## 冻结的历史矩阵

仅使用现有8个历史系统的切入/切出，每库512坐标。逐次将一个历史系统作为伪目标，其余7个为来源；不加载开发或正式目标数据，也不使用旧深核教师。每任务预算128，初始8个取`default_rng(1301).permutation(512)[:8]`，包含在预算内。三个设置各16项，共48项历史隔离回放、6,144次历史等效查询。

每个来源以自己的全部512条历史碰撞标签训练64棵极端随机树，最小叶样本数4、全部输入特征可用于分裂、无bootstrap、单线程、种子1301。该来源的预测概率为响应特征。伪目标自己的森林从来源中排除；历史各来源森林可在不同伪目标间复用，但不把自身输出传给自身回放。来源按标识排序，仅用于稳定计算；不以目标身份或家族决定选例。

对来源预测按现有家族均衡先验求平均，得到静态历史概率`h(x)`。三个目标树输入固定为：

1. 归一化物理/类别特征`x`。
2. `[x,h(x)]`，单一汇总响应控制。
3. `[x,p_1(x),…,p_7(x)]`，逐来源响应特征。

三者均从已查询目标标签拟合64棵极端随机树，最小叶样本数2、全部输入特征可分裂、无bootstrap、单线程；每步从头拟合，种子`1301+已查询数`。初始化前目标树概率取0.5，之后单类训练按其唯一类别概率处理。查询分数统一为`0.9 p_tree(x)+0.1 h(x)`，相同分数容差1e-12时按场景标识排序。三个设置的历史先验、适配次数和模型规模相同，不增加网络或安全量反馈。

## 信息隔离、指标与筛选

使用现有`run_isolated`及`QueryLedger`，选择器只接收公开候选、组装后的特征与静态历史概率。碰撞标签通过查询接口逐条返回；完整伪目标标签、全库分母及轨迹留在评估端。来源训练、目标拟合、选例和回放成本分别记录。所有原始历史档案只读，不新增仿真或开发选例。

历史伪目标与其他历史来源的512个坐标相同，来源森林已见过其他系统在这些坐标上的标签；这属于允许的历史经验，不是目标标签泄露，但也不能证明对新坐标的插值泛化。即使本筛选通过，后续在未见坐标和开发对象上的验证仍不能省略。目标森林在每次预测之前用已有反馈拟合，末次查询后不再执行不用于任何选点的拟合。

报告128次去重碰撞数、全库去重碰撞召回、16/32/64预算点、完整曲线及AUC；零碰撞任务保留数量零、召回不适用。先在历史谱系内汇总两个场景，再等权汇总8个谱系。只有一个历史选例种子，结果只是筛选证据，不表述为最终置信结论。

逐来源版本需要同时优于物理特征和汇总响应控制的平均召回，平均发现数及AUC不降低，且相对每个控制至少两个有碰撞历史谱系召回改善，才保留为下一步机制研究线索。未通过时不继续调树规模、历史混合质量或种子，不增加开发矩阵。通过也不等于原阶段B或后续50%漏检减少门槛通过；后续方法、消融和所有38种强参考必须另行冻结。

## 命令与验收

先执行`python -B -m benchmark.discovery_tree_screening prepare`、`smoke`、`run`，再执行独立入口`python -B -m benchmark.discovery_tree_screening_audit`，最后执行`python -B -m benchmark.discovery_tree_screening_report`。三项实际首轮属于48项；首轮预算/反馈核对通过后再运行其余项。输出在`results/benchmark/collision/discovery/tree_screening/`，来源预测与训练成本单列。要求历史角色及自身排除、48条完整预算账本、6,144条反馈、全库去重分母、共同初始化和曲线一致；在查询9/65/128独立重拟合目标森林并重算全部512候选及选点，共144组。原正式目标、旧结果和准入门槛保持不变。

48项回放完成后的首次审计在JSON反馈字典比较处停止：内存中的`violations`为元组，落盘后为列表。另逐条对照6,144条原始反馈，转回`QueryFeedback`后的测量差异为零，只有该序列化类型差异，证据在`audit/serialization_diagnosis.json`。冻结选择器、协议和运行文件保留；独立审计使用规范化的反馈对象比较，同时重新核对完整矩阵及144组选点，并加入10项损坏控制。全部48项查询复用，首次失败审计成本与修正后的审计成本分别保留在`orchestration/original_pipeline.json`及`progress.json`。冻结文件内的原`audit`阶段只保留为该次失败的源码证据，后续使用上述独立入口。

首次报告还因NumPy比较结果产生非原生布尔值而停止。独立汇总入口使用原生数值和布尔类型，补充两项回归检查，覆盖谱系等权、缺失召回及JSON序列化。原始运行与数值均未修改；失败及修正成本保存在`orchestration/canonical_pipeline.json`和`progress.json`。冻结文件内的原`report`阶段同样只保留作历史源码证据。

后续仍为48项历史回放、6,144次历史等效查询，使用本轮相同的召回/数量/AUC/两个谱系筛选条件；没有新增树规模、先验质量、随机种子或目标对象调参。拟合折、每个来源的训练/预测索引、全部折外预测、预算账本及独立全候选重建应保存至独立的`tree_crossfit/`目录。协议须在读取该项结果前冻结，回放与审计必须通过后才讨论开发矩阵；实际验收另行记录，不以协议定义代替完成证据。

## 历史辅助响应的来源端诊断定义

在读取这项新结果前固定如下检查，输出独立保存于`source_safety_prediction/`。复用相同16个历史来源、五折索引及源分类器折外概率，不调树规模、叶样本数、先验质量或随机种子。来源回归器使用[ExtraTreesRegressor](https://scikit-learn.org/1.7/modules/generated/sklearn.ensemble.ExtraTreesRegressor.html)，64棵、最小叶样本4、全部特征可分裂、无bootstrap、单线程、种子1301，联合预测现有档案的归一化间距与TTC；规范化直接复用`ResponseArchive.auxiliary`。每折只拟合训练坐标上的历史安全量，共80次来源拟合。

以来源真实碰撞Boolean作评估标签，分别报告原折外碰撞分类概率、负预测间距、负预测TTC的平均精度及ROC AUC，不将连续安全量按阈值改写成碰撞。间距为预定主要通道，TTC仅作辅助分析，不据结果换主通道。主要通道只有在两个场景的来源谱系等权平均精度均严格超过源分类概率、ROC AUC不降低、且各有至少两个来源谱系平均精度改善时，才提供后续历史表示研究线索；无碰撞来源保留，排序指标不适用，回归误差照常统计。该条件不等于迁移、在线发现、阶段B或独立目标验证通过。

同时逐折按训练叶的安全量均值独立重建预测，并检验翻转一整折的未查询安全量不影响该折输出。整个检查不训练目标分类器，不执行新的历史搜索回放，不读取开发或正式目标标签，不改变`QueryFeedback`或选择器轨迹权限。入口为`python -B -m benchmark.discovery_source_safety_prediction`，必须通过80个来源模型及全部16个任务核对才汇总。

来源端诊断已全部完成。80次多输出回归、8,192个折外坐标的两个通道预测均与独立训练叶均值一致，最大误差低于3.4e-16；未查询安全量污染不改变该折输出，48条排序指标及其汇总另经独立核对。计算经过3.45秒，无新增历史搜索、开发选例、神经网络训练或物理调用。
