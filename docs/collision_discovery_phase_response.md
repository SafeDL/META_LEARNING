# 按交互阶段迁移历史失效响应

## 研究假设与进入原因

原二值原型和联合响应、物理分量两组扩大验证均未通过各自登记门槛，结果保留。下一步检验更具体的问题：**早期碰撞会中止执行，后续阶段的响应未被观察；把不同交互阶段的碰撞合成一个标签，是否削弱了历史经验对稀有后续碰撞的帮助？**

已有24份档案核查显示，PPO开发系统切出的22次碰撞包括横移前16次、横移中4次、横移完成后2次。多数方法完整找回前20次，却持续漏检最后两次。历史PPO的25次切出碰撞没有完成后碰撞，其他历史系统合计存在32次此类碰撞。这是阶段内来源互补的开发线索，不能据此删去早期碰撞、筛选目标或宣称所有场景都具有同一结构。

阶段分解、离散生存概率及删失均作为已有统计工具，不单独宣称原创。待验证的贡献是：在跨系统碰撞搜索中，以实际观察到的阶段为条件复用响应和评价来源，避免早期失效代替尚未观察的后续阶段反馈。最终仍由总真实碰撞发现、机制对照与独立目标支持。

## 反馈定义与概率模型

使用三段既有背景交互：明显横移开始前、横移过程中、横移完成后直到10秒。起止点沿用已有轨迹重建阈值，不以目标是否碰撞调整。切入、切出均采用相同规则，不把模板名称当成实际碰撞机理。

对已执行场景生成三个条件标签。若在第k段首次碰撞，第k段为1、此前各段为0、此后各段为未观察；没有碰撞且观察到完整10秒时，三段均为0。安全执行若提前结束，只标记已完整观察的段，其余未观察。既有完整库没有这类安全提前结束，但定义仍保留正确的删失含义。

每阶段建模在此前存活条件下的碰撞概率q_k(x)，总碰撞概率采用离散生存分解：

\[
P(C\mid x)=1-\prod_{k=1}^{3}(1-q_k(x)).
\]

各阶段潜在GP分别近似推断。该计算是工作模型，不保证完整联合后验或概率校准。阶段可靠性只用实际观察到的阶段标签的查询前预测更新；没有观察到的后续阶段不参与损失或来源评分。

旧`QueryFeedback`和冻结源码保持不变。未来在线原型另设有界阶段反馈包装，只返回本次已付费查询的三个标签与可观察标记；不授予选择器全库标签、分母或轨迹访问权限。全库阶段记录仅供评估和历史构建。

## 第一项诊断：先检验阶段信息与删失

该诊断使用现有主方法40条完整轨迹各127次已付费前缀。只重建预测，不新增选例、仿真或训练目标系统。全部开发任务保留，包括零碰撞任务；输出与旧实验隔离。

预先固定两个初始化：原联合响应编码器、原FSBO编码器。每种初始化比较三种配置，共40×2×3＝240项预测：

| 配置 | 历史阶段后验 | 未观察阶段处理 | 目标反馈 |
|---|---|---|---|
| phase_transfer | 8个历史来源，各阶段分别保留 | 不进入损失和后验 | 同一127次查询的阶段标签 |
| phase_target | 无历史阶段后验 | 不进入损失和后验 | 完全相同阶段标签 |
| phase_zero_fill | 同样8个来源，按此规则重新拟合 | 作为0 | 完全相同阶段标签，再填充未观察项 |

这一步固定来源权重，历史来源合计0.75、独立目标0.25，历史来源内按家族等权。不在此诊断中预先宣称已验证阶段可靠性。总概率再与同前缀仅使用二值碰撞的物理GP按0.90/0.10混合，物理分量与前一轮规则一致。所有配置都使用相同物理预测。

基础核、网络及参数初始化继承现有两个冻结模型；每阶段基础均值改为历史来源在该阶段风险集上的平滑碰撞频率的logit。按来源家族权重计算有效碰撞数与风险集样本数，使用`(a+0.5)/(n+1)`平滑。零填充消融保持同一基础均值，以隔离观察标签处理的变化。初步验证不额外训练网络宽度或深度。

历史来源每阶段只使用本来源实际观察的阶段标签，从对应基础模型适配10步、学习率0.003、梯度裁剪5，再用完整历史支持集构造该阶段的Gaussian/Laplace后验。零填充版本将未观察项作为0另行适配。目标每阶段从同一基础初始化重置，使用已付费前缀中实际观察的标签适配相同步数；没有该阶段观察时不适配。迁移采用来源后验均值加目标均值变化、来源后验协方差加目标核；来源独立目标分量同时保留。原先迁移先验属于已有方法基础，此处不作为新增原创结构。

剩余385个候选的标签只用于评估：报告全部候选NLL、Brier、全部剩余真实碰撞的排名、分阶段碰撞排名，以及每谱系差异。先在谱系内汇总再等权汇总；无剩余碰撞的排名为不适用。另列历史构建与预测重建时间。这些预测指标不能替代128次在线发现门槛。

必须通过的数值核对包括：12,288条既有记录的阶段标签与原碰撞标记一致；阶段未观察项不变成安全反馈；早期碰撞、生存至下一阶段、末段碰撞和安全提前结束的标签边界正确；三段概率分解在边界上正确且位于[0,1]；目标模型看不到未查询阶段标签；独立NumPy推断核对完整候选概率；无来源配置恢复同一目标GP；旧冻结协议不变。

入口计划为`python -B -m benchmark.discovery_phase_response_diagnosis`，输出在`results/benchmark/collision/discovery/phase_response/`。新增方法组件位于`methods/gcrt/phase_response.py`，数值测试置于对应`tests/`目录。诊断代码、构建与结果均不写回旧冻结目录。

## 在线验证的进入条件与规模

先完成上述诊断及同信息对照。如阶段信息与删失没有显示可重复的预测差异，保留结果，不为这一路线自动增加网络或扩大仿真。预测改善仅用于是否值得进行开发试验的判断，不能作为阶段B成功。

若进入在线试验，先登记唯一主配置及完整机制矩阵，再运行：阶段来源可靠性、跨阶段共享来源可靠性、无历史阶段目标模型、零填充删失消融，以及同预算二值最强参考。每个新增配置仍为40项运行、512候选、128查询含8次初始化、五个既定配对种子、环境种子81001。固定权重原型如参与选型也须保留完整40项，不在看到终点后更换主方法。

阶段反馈必须经隔离查询接口逐项获得，同信息目标模型和共享可靠性消融获得完全相同的信息。评分保存查询前概率，只在已观察阶段更新；虚拟反馈与前瞻暂不加入。先验证阶段标签、隔离接口及查询账本，再登记在线矩阵，不直接把评估端原始记录交给选择器。

强参考包括此前14种方法及刚完成的全部8种物理分量方法，共22种，均为完整40项。当前最高平均召回为`physical_local`的98.585721%，因此下一轮主方法需要至少99.292861%召回、平均碰撞数不低于最强参考，并在至少两个有碰撞的开发谱系上取得正收益。若最强参考改变，按同一公式重新计算。参考100%时比值为不适用，不视为通过。

方法机制另由主配置与同信息控制比较确认。旧失败结论、全库分母、去重、零碰撞库和配对分层区间规则保持。阶段C、D、E仍不进入；通过开发试验后还须重新训练与最终推断一致的完整历史模型，支持集8/16/32/64/128，并完成最接近的层次GP迁移与RGPE对照后才能冻结正式方法。

240项初步诊断中的`phase_target`共享原冻结编码器和历史阶段的基础均值，控制目标阶段反馈的信息量；它没有利用全部历史阶段标签重新元训练表示。因此若诊断显示正信号，在登记在线主矩阵之前，还须加入以相同历史阶段标签训练的Pooled-FT/FSBO阶段模型；主方法与这些控制共享相同阶段表示和模型容量。不能把“新历史阶段训练”相对“旧二值表示”的差异单独归因于逐来源迁移或阶段可靠性。

新场景和八条正式目标路线继续执行原[总方案](collision_discovery_plan.md)，不按当前两个漏检坐标改变参数范围或更换正式系统。

## 已完成诊断与下一步

上述240项预测已全部完成。12,288条阶段标签与角色档案逐项对应，4,560组全512点分量概率通过独立NumPy/SciPy推断核对；阶段及条件适配组件合计21项测试通过。历史阶段后验构建130.00秒，诊断总耗时504.05秒，新增选例和物理调用均为零。完整[结果](../results/benchmark/collision/discovery/phase_response/report.md)与原二值实验分开保存。

联合初始化下，迁移版本NLL为0.092908、Brier为0.011341，虽优于同阶段信息目标模型的0.142879、0.028375，但剩余碰撞平均排名反而从102.572降至156.417。FSBO初始化下，迁移版本对应为0.312576、0.092598、133.344，目标版本为0.605819、0.188712、93.089。删失版本没有稳定优于填零消融；索引90也未获得一致排名改善。本轮没有支持完整在线试验的充分证据，不据这些预测宣称发现收益或删失机制有效。

进一步只用历史风险集频率和公开候选特征，发现初始均值的转换需要单独核查：对潜在均值取`logit(frequency)`并不保证Gaussian潜变量积分后的边际概率等于该频率。FSBO切出完成后阶段的平滑历史频率为1.0025%，原核潜在方差约6.685时，初始独立目标分量的边际概率实际为7.2001%。这是一项初始化不匹配，不足以解释全部排名结果。

入口`python -B -m benchmark.discovery_phase_prior_diagnosis`已复核12项初始化，匹配均值使原核下的初始边际概率等于相同历史频率；匹配结果与先前独立计算一致，22项联合数值检查通过。输出为[初始化核查](../results/benchmark/collision/discovery/phase_calibration/prior_check.md)。该匹配不保证来源协方差叠加或后验适配后仍校准，不以此作为方法性能证据。

下一项诊断已登记于`phase_calibration/design.json`，仍为相同40个付费前缀、2个初始化、3个配置，共240项预测。**只改变基础均值的初始化**，按下式求解，历史频率、核、来源构建、删失规则、10步适配、固定权重和物理质量均不改变：

\[
\frac1{|\mathcal X|}\sum_{x\in\mathcal X}\mathbb E_{Z\sim\mathcal N(0,1)}
  [\sigma(m_{0,k}+\sqrt{K(x,x)}Z)]=\widehat q_k.
\]

`q̂_k`只由历史阶段风险集计算，`X`为公开候选特征，不使用开发目标结果选取均值。原240项预测保持原样，新结果输出至`phase_calibration/`。完整比较入口`python -B -m benchmark.discovery_phase_calibration`已实现，并在22项组件检查、12项初始化检查及旧协议一致性检查通过后启动；运行前已冻结`phase_calibration/protocol.json`，每项另核对原前缀的阶段支持集完全相同。完成这一解析属性修正后再判断是否需要按阶段重新训练共同表示；不自动增大网络，不进入在线矩阵或C/D/E。

这一重复现已完成，4,560组全512点分量概率与240项支持集核对通过，最大独立概率差小于8.26e-9；总耗时497.60秒，历史来源构建128.33秒。完整[匹配初始化结果](../results/benchmark/collision/discovery/phase_calibration/report.md)仍没有支持扩大在线投入的排名收益：联合迁移平均排名从156.417变为180.372，FSBO迁移从133.344变为193.839。联合版本NLL虽降至0.086752，FSBO版本NLL约0.312027，但误差变化没有转化为更好的剩余碰撞排序。删失版本也没有稳定胜过填零。

因此暂不为阶段反馈路线追加网络训练或在线矩阵。下一项回到碰撞为唯一在线监督，按[残差尺度方案](collision_discovery_residual_scale.md)用历史系统之间的响应差异学习残差幅度；不以开发目标结果挑β，不改变原预算、驾驶系统或旧失败结论。
