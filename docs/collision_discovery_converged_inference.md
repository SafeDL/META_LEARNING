# 来源条件推断收敛性：修正与历史复核

## 问题证据及解释边界

[虚拟反馈的模式审计](../results/benchmark/collision/discovery/counterfactual_adaptation/mode_audit/cached.json)检查了368个模式，18个未满足白化梯度1e-6容差，最大残差122.4167。它们全部来自历史来源分量：6个属于真实64点历史前缀，12个属于可由缓存覆盖的虚拟分支；本次检查中的独立目标和物理分量没有发现该问题。与独立收敛求解比较，单分量概率差最大0.994820，不能将此数值直接解释为最终混合概率差。

这项证据说明固定10步无阻尼迭代不能在所有来源/目标组合下给出收敛模式。旧实验的已付费反馈、发现数、召回率及失败结论仍是其登记实现的实际结果；数值一致性审计只复现该实现，不足以支持将机制差异完全归因于来源、局部权重或目标核适配。

下一步优先隔离数值求解的影响，再考虑新增机制。收敛求解属于正确性修正，不单独作为研究创新。当前RGPE和ScaML设计保持冻结，修正不在其中途加入；新开发比较须等待强基线完整结果及另行登记。

## 固定修正规则

新增`methods/gcrt/converged_response.py`，对各历史Gaussian先验及独立目标分量使用已有白化阻尼Newton求解器，要求白化梯度不超过1e-10。沿用1e-5训练稳定项、目标深核、历史均值/协方差及边际概率积分，不提供未收敛模式的静默替代。真实与虚拟标签均采用同一条件推断规则。

本轮历史复核继续使用原8个历史系统、切入/切出、512历史坐标、种子1301的128点有序支持集与不相交32点查询集。目标模型的129个适配状态取自已有CUDA缓存；独立推断和参数复核在CPU执行，不新增网络训练、开发查询或物理执行。自身来源从上下文排除，教师仍曾使用全部历史对象，本项不是严格留系统验证。

来源先验保持0.75、独立目标0.25，外层物理质量0.10；局部距离仍用原归一化场景参数，带宽0.30，全局对照为κ=1。每个标签的可靠性得分始终来自查询前预测。

## 阶段与对照

1. 在原选中β和64点支持处，核对全部16个历史任务。比较旧预测/旧权重、收敛预测/旧权重，量化直接预测修正与旧可靠性权重的遮蔽效应，不预先假定混合预测也有近1的差异。
2. 对β=`0、0.1、0.3、1、3`重新执行历史学习，保留局部/全局两种可靠性。分别记录旧预测及旧权重、收敛预测及旧权重、收敛预测及重新累计权重三类，共`16×5幅度×2可靠性×5支持规模×3类型=2,400`项评分。
3. 收敛局部版本仅根据历史查询集NLL、Brier、距离β=1、β的原顺序选幅度，两个场景分别选择。旧幅度及旧失败结论不改写。若要启动新开发搜索，必须先冻结主配置、单位幅度及全局控制、同信息目标控制和届时全部强参考，保持128次预算与50%漏检减少门槛。

支持规模仍为8、16、32、64、128。先在历史谱系内汇总，再等权汇总。完整保留所有配置与零碰撞历史任务；预测损失不替代碰撞发现指标。

## 入口与验收

入口为`python -B -m benchmark.discovery_converged_response prepare`、`prefix`、`history`。输出位于`results/benchmark/collision/discovery/converged_response/`，独立于旧历史选参、模型、协议及发现结果。

先核对：已收敛低方差例与旧实现一致；已知振荡例被修正且符合独立收敛推断；来源排列不改变结果；输入及真实状态不变；无反馈返回原先验。所有求解记录迭代数、梯度残差及回溯数，失败即保留任务、前缀、参数与成本并停止。

历史学习在0、8、64、128支持点对全部幅度作独立NumPy/SciPy收敛概率核对，共320组分量预测。旧评分另外与原800项登记结果对照，确保目标模型、上下文和权重规则没有夹带变化。模式审计的完整CUDA部分继续等待RGPE结束，不以缓存子集代替全量验收。

## 历史复核结果

全部16个历史任务、2,400项评分已完成。81,920次非空条件求解均达到1e-10梯度阈值，最多17次迭代；320组独立概率核对最大差1.70e-11，原800项评分最大复现差6.68e-14。独立汇总审计重新得到切入β=1、切出β=1，原切入β=0.3的选择保留不改。历史学习耗时383.98秒，未增加开发查询或物理调用。[完整结果](../results/benchmark/collision/discovery/converged_response/report.md)包括全部配置，不能将选中β的预测损失当作开发发现收益。

在原64点前缀处，三个任务的单来源概率有明显修正，但旧可靠性权重抑制了其混合影响：Beam切出最大混合差0.012449、DQN切出8.72e-7、FVDM切出0.000447。因此单分量近1的差异不等于整体方法有同幅度问题，也不预先证明修正能通过发现门槛。收敛后的局部查询集NLL在两个场景仍略高于全局，局部机制优势必须由后续配对搜索检验。

## 新开发比较的冻结矩阵

后续唯一指定主方法为`converged_local`，其余三个为相同β的`converged_global`、不显式读取来源后验的`converged_target`及使用两种已有教师的`converged_dual_target`。每种覆盖原40项任务，共160项、20,480次等效查询；首轮四项计入矩阵。两个场景均选中β=1，不重复增加相同参数的单位幅度运行，直接与旧`residual_unit_local/global`比较求解器修正前后。历史教师、来源Gaussian先验、目标核适配协议和外层物理质量保持一致。

四种方法的条件推断统一在CPU双精度执行，核构建与10步目标适配沿用原CUDA后端；不将缓存中的CPU训练替代成等价实现。每次记录所有来源、独立目标与物理分量的最终梯度、迭代及回溯数。选例仅用真实碰撞Boolean，仍为概率贪心；全库标签、轨迹和召回分母只由评估端读取。

注册时列入全部34种前序方法，并将本轮两个收敛目标控制加入最强参考选择。门槛继续要求相对最强参考减少至少50%剩余漏检、数量不降低、至少两个有碰撞谱系正收益；局部还须召回严格超过全局且数量不降低，并胜过双教师同信息控制。参考召回饱和或不足两个谱系存在提升空间时，先输出数学可达性证书，不通过更换参考或主方法解决。

入口为`python -B -m benchmark.discovery_response_geometry prepare`、`smoke`、`run`，随后运行`python -B -m benchmark.discovery_response_geometry_report`。输出在`converged_search/diagnosis/geometry/`，完整报告保留三个查询位置和四种核。40项/120状态/78条案例记录全部完成并独立复核；原核最大复现差3.19e-13，独立加权分数差为零，平均方差最大差4.45e-15。两项专门检查覆盖合法核、方差与尺度控制。扩展批复用一项首轮、增加39项，共享机器经过75.05秒，新增工作进程复现合计128.81秒；新增查询和物理调用均为零。

## 下一项历史筛选：保留与适配两种碰撞几何

在读取该项新结果前固定以下筛选。复用原16个历史任务、种子1301的128点有序支持及不相交32点查询、原129个CUDA适配缓存；不增加网络训练、开发查询或物理调用。自身来源从显式后验排除，教师仍使用全部历史系统，所以这项筛选不是严格留系统或留家族泛化证据。

比较四种构造：仅适配碰撞核、仅冻结碰撞核、每个来源内两种核的概率固定各半、来源与核视图共同按查询前似然学习可靠性。全局及物理距离局部κ（带宽0.30）各作一份，共8种设置；支持规模8/16/32/64/128，共640项评分。两种核使用相同当前均值、来源Gaussian先验、β=1和平均边际方差；独立目标保留0.25先验质量，来源组0.75，外层物理分量0.10。学习视图从各半质量开始，查询前产生似然后再更新，不以拟合该标签后的预测重算过去得分。固定各半版本先在来源内平均概率，再更新来源可靠性。

不新增带宽、视图先验或温度选参。预定局部学习视图须在两个场景分别满足：谱系等权查询NLL严格低于同为局部的三个构造及其全局学习视图控制，Brier均不提高，且相对最强局部构造至少两个历史谱系NLL改善。未达到则结束该分支，不依据开发遗漏继续调节视图权重；即使达到也只表示值得设计新的在线矩阵，不代表阶段B通过。

入口为`python -B -m benchmark.discovery_geometry_retention prepare`、`run`，输出在`results/benchmark/collision/discovery/geometry_retention/`。要求128组独立分量预测核对、全部640组权重与概率顺序/矩阵交叉核对、原适配控制160项评分复现，以及保存数组的独立汇总；任何失败保留任务和成本并停止。当前160项在线矩阵、旧证据及最终目标保持冻结。
