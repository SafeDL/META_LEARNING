# 历史后验与目标反馈互补：研究主张和证据路线

更新日期：2026年10月24日。依据用户最新意见，核心研究问题收紧为：**在固定测试预算下，显式复用历史系统响应后验，与少量目标系统反馈结合，能否比单独使用其中一项更早、更多地发现碰撞？**

本次采用研究主张调整。局部权重、来源协方差和前瞻分别接受消融检验，由结果决定是否进入最终方法。原400项前瞻比较建议转为后置备选，不作为当前默认执行矩阵。原方法、失败结论、128次预算与50%漏检减少准入规则继续保留；新研究主张不把旧准入改为通过。

## 研究主张与解释边界

历史表示训练与显式历史后验是两个不同的信息使用方式。本研究在相同历史训练信息及目标反馈条件下，检验保留各系统响应后验的额外作用，不能将“去掉显式来源后验”称为“完全没有历史信息”。

核心证据需要同时回答：

1. 在允许目标反馈时，加入历史后验是否提高固定预算内的发现收益？
2. 在拥有历史后验时，目标反馈是否优于静态历史排序？
3. 上述作用能否在未参与设计的系统、场景和留家族条件下复现？

来源集合的失效交集、事后最佳来源、两次独立搜索的发现并集只用于解释潜力。已有`complementarity/report.json`中的并集成本为256次查询，不能充当本轮128次互补模型的结果。预测损失、固定状态排名和虚拟批量潜力也不替代完整搜索收益。

单来源后验迁移、多来源集成和标准ENS的定位沿用[已核查文献与证据要求](collision_discovery_method_positioning.md)。核心问题收紧后，仍须说明具体机制和实验发现，不能仅以重新命名建立创新性。

## 当前已具备的证据

完整开发条件为8个历史对象、4个开发对象、切入/切出、每任务512候选、128查询、8次共同初始化、5个配对种子。当前统一强参考汇总有38个方法/配置；累计2,360项有效完整开发搜索。多个配置和种子不等于更多独立被测系统。

| 对照 | 当前观察 | 能支持的判断 |
|---|---|---|
| 收敛局部版与FSBO | 召回+2.7245个百分点，95%区间[0.5700,4.8679]；数量+1.000 | 开发集上的整体改进已存在 |
| 收敛局部版与同信息双目标控制 | 召回+1.6756个百分点，95%区间[0,3.7045]；发现AUC+1.3018，区间[0.1488,2.6383] | 显式历史后验在相同局部可靠性规则下具有发现速度线索；终点优势仍不充分 |
| 收敛局部版与全局版 | 召回+0.0183个百分点，区间跨零；AUC下降 | 尚未建立局部权重的稳定独立收益 |
| 已有联合模型的独立/共享协方差及仅均值消融 | 召回差很小，区间跨零 | 协方差结构仍需匹配复验，不能预设为必要贡献 |
| 固定历史状态的剩余预算前瞻 | 平均实际批量潜力+0.125；五步无收益 | 只形成后续选例线索，尚无完整在线收益 |
| 新系统和严格留家族验证 | 尚未完成 | 当前不能支持独立泛化结论 |

特别需要补齐的匹配点：`converged_global`使用全局可靠性，而现有`converged_dual_target`使用局部可靠性。二者可报告整体差异，但不能作为“只去掉历史后验”的严格全局消融。对应代码分别位于`methods/gcrt/converged_search.py`的来源分量构建及带宽选择处。新的全局控制应另行登记，旧结果不覆盖。

## 下一项最小机制实验

采用历史后验H与目标反馈F的2×2设计。所有单元使用相同候选、初始化、预算、教师、物理分量、收敛求解和贪心规则；可靠性固定为全局。选择全局骨架是为了隔离互补问题，不将其认定为最终主方法或当前最佳配置。

| 单元 | 显式历史后验H | 目标反馈F | 定义 |
|---|---|---|---|
| H0F0 | 无 | 不用于模型更新 | 保留同信息聚合历史教师、FSBO初始化与物理先验，固定初始预测和权重 |
| H1F0 | 有 | 不用于模型更新 | 固定逐来源历史后验、目标初始核和初始权重，静态排序 |
| H0F1 | 无 | 使用 | 聚合历史教师、FSBO及物理模型使用已付费碰撞适配；全局查询前可靠性更新 |
| H1F1 | 有 | 使用 | 当前`converged_global`骨架，逐来源后验加目标残差，进行相同条件化和全局更新 |

H0并非从零学习：它保留与H1允许使用的同批历史训练信息，控制显式逐来源后验的作用。H0学习组由联合响应教师与FSBO构成，先验质量0.75/0.25；H1为各来源按原谱系先验分配总质量0.75、目标分量0.25。两者外层物理质量均为0.10。H0聚合分量替代来源组属于明确处理差异，分量数及适配成本分别报告。

F0仍支付全部查询并由评估端计数；选择器只把已查询坐标移出候选集，初始化和后续标签均不用于条件化、权重更新或核适配。F1在线只用碰撞Boolean，已付费间距/TTC和轨迹不进入模型。来源和目标核、β=1及全部适配参数沿用已验收定义；首轮不加入局部化或前瞻。

所有单元采用原1e-12分数并列规则及场景标识排序。无显式后验、无反馈的先验可能对候选给出相同概率，因此H0F0是预先固定的无信息静态策略；已有随机方法另列参考，不把这一锚点的偶然表现作为协同机制的证据。

规模为`4单元×4开发对象×2场景×5种子=160项`。H1F1的40项仅在完整逐次预测、选点、可靠性及配置一致性检查通过后复用原运行；其余3单元新增120项，即15,360次等效查询、零新增物理调用。此处只定义下一项实验，当前尚未新增实现、冻结协议或启动运行。

当前H1F1的性能已知低于最强参考，因此本组是机制诊断，不是一项尚未揭晓的新原型准入尝试。补齐控制本身不会改变H1F1的发现数，也不能据此自动进入D/E。

## 评价与停止规则

主比较为`H1F1−H0F1`和`H1F1−H1F0`，分别检验反馈存在时的后验收益、后验存在时的反馈收益。报告128次去重数量、召回及发现AUC，并保留16/32/64预算点和完整曲线。全库无碰撞任务按原规则保留，召回不适用。

对每个主比较分别检验两类预定证据：终点改善要求平均召回严格提高、平均数量不降低；速度改善要求发现AUC严格提高、128次数量及召回均不降低。只有两个主比较均具有对应收益，才支持相应的互补结论，不在报告后改选最有利指标。若只有AUC改善，结论限定为更早发现；若终点区间含零，不写为稳定提高最终召回。对两个主比较分别报告配对分层区间，不仅展示获益谱系。

交互量`Δ=M11−M10−M01+M00`作为辅助分析。正交互可支持超加性的线索；互补不预设必须超加性，负交互也不能凭空取消联合模型相对两个单项的实际收益。所有判断同时考虑零任务、四个独立开发谱系及无信息锚点。

机制实验完成后统一评估，不因某个单元更好而追加权重、教师、种子或窗口搜索。当前开发集已反复使用，新增对照仍是开发证据；不得把它包装成独立确认。无机制收益时保留负结论，回到历史任务提出具体假设，不自动扩大网络或改换目标。

后续新原型若申请进入原D/E，仍须在届时全部强参考下满足50%漏检减少、数量不降低、至少两个有效谱系正收益及同信息控制要求。局部、协方差或前瞻的专门条件仅在新方法实际采用相应机制时另行冻结；原已冻结主方法的准入判断不改写。

## 可选机制的处理

- 局部权重：只与同预测模型、同反馈和同选例的全局权重配对；当前证据不足以强制纳入。
- 来源协方差：分别比较完整来源协方差、共享来源协方差和仅均值；目标残差、均值、权重及适配保持匹配。旧联合模型结论不冒充最新收敛模型的复验。
- 前瞻：固定预测模型后，同步给主方法和同信息控制加入相同窗口。已有400项建议及其计算准备保留为备选，不因实现加速而默认投入该矩阵。
- 物理分量：若拟将其列为核心机制，补齐只移除该分量的匹配对照，区别来源迁移收益与普通模型融合收益。

不把三项可选机制叠加成必须成功的整套结构。最终保留的复杂度须有明确用途和独立证据，删减依据在新目标标签开放前写入冻结协议。

## 独立验证必须保留的范围

原方案的四类旧场景、新增邻道开放/受限切入任务、八条路线的新目标、五个配对种子、512候选/128查询、全来源与严格留家族条件全部保留。新增任务两个条件共用预算，几何和事件时序按统一规则验收，不按系统碰撞结果选择样本。

采用原[独立目标配置表](collision_discovery_plan.md)中的六个非学习配置，以及PPO/DQN独立种子5107/5113，使用新对象标识与专属记录。旧目标标签仅解释旧结果，不替代独立确认。所有新对象先通过五项基本能力检查；失败时记录原因，不按测试算法结果替换对象。

实际开跑前依次完成：

1. 机制诊断与完整方法准入；确定一个方法及必要消融，保留全部开发选择记录。
2. 新任务历史/开发响应采集、最终模型一致性重训，支持规模8/16/32/64/128；新增场景单独登记。
3. 新目标对象登记、独立训练和资格验收。资格轨迹与搜索标签用途分离。
4. 严格留家族时同时排除该家族的历史训练、上下文及开发选参，冻结模型、选择器、指标、数据和全部矩阵。
5. 冻结后一次性完成独立矩阵，全部系统均保留。根据新目标结果修改的方法只属于后续探索，原确认结果不覆盖。

仅新目标五任务完整库就需要`8×5×512=20,480`次场景执行；新增任务的8历史/4开发响应为6,144次，策略训练、资格和失败重试另计。它们属于后续D/E建设成本，不挤入首轮2,048次开发补采额度，也不在本次文档更新时启动。
