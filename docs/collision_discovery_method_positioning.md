核查日期：2026-10-23。本文针对正在开发的历史响应迁移、独立物理分量和预算选例核对直接相关原始论文，服务于[执行方案](collision_discovery_plan.md)的机制定型。它是定向核查，不是完整系统综述，也不构成“首次提出”的证明。已结束实验及当前240项残差尺度实验的配置、强参考集合和准入标准保持冻结。

## 单来源后验与层次GP的对应

AISTATS 2022推论1给出的目标先验为

\[
f_t\mid\mathcal D_s\sim\mathcal{GP}\!\left(
\mathbb E[f_s\mid\mathcal D_s],\,
k_t+\operatorname{Cov}[f_s\mid\mathcal D_s]\right).
\]

当前实现采用来源均值`μ_s+(m_t−m_H)`及协方差`K_t+C_s`。在去除均值中心化记号后，其单来源先验与上述结构对应。这是对公式的比较，不是对整个算法等价的断言：本项目使用碰撞的Bernoulli似然、可选连续间距、多来源混合与在线深核适配；这些扩展仍须分别解释和验证。[原始推论及推导](https://proceedings.mlr.press/v151/tighineanu22a/tighineanu22a.pdf)

因此，后续表述应将层次GP作为方法基础。可检验的研究主张是：跨控制器响应在何种失效区域具有可迁移性，以及相同目标反馈下，这种响应迁移能否超过共享表示和普通目标模型组合。

## 当前实验能证明什么

| 研究问题 | 已冻结的证据入口 | 解释范围 |
|---|---|---|
| 来源响应后验是否有独立收益 | `physical_global` 对 `physical_target` | 相同历史表示、物理分量及已付费碰撞反馈下，比较提供来源后验的效果 |
| 来源协方差是否值得保留 | `physical_global` 对 `physical_mean` | 分别报告数量、召回、曲线和成本；由实际差异决定是否保留该复杂度 |
| 来源可靠性是否需要局部化 | `physical_local` 对 `physical_global` | 根据完整结果保留相应机制；旧局部主方法失败结果另行保留 |
| 持续保留物理质量是否优于普通自适应融合 | `physical_global` 对 `physical_adaptive` | 两者从同一质量开始，比较固定保留与查询前二值得分更新 |
| 普通目标模型混合是否已足够 | `physical_fsbo` 对 `fsbo_cuda`，并与主方法比较 | 区分一般混合、同后端适配和来源响应迁移；当前两个完整对照已显示局部收益与整体发现数损失并存 |
| 预算前瞻是否有额外价值 | 阶段C的贪心、五步与剩余预算比较 | 在开发准入后执行；标准ENS收益式与本项目的可靠性更新分别说明 |
| 收益能否推广到新系统和交互任务 | 阶段D/E的新对象、统一开放/受限任务、严格留家族 | 开发集结果只提供进入条件，独立系统结果支撑最终结论 |

如果后续将“加入物理分量”作为必要机制，还应补齐仅移除该分量的全局、仅碰撞在线监督对照；已有旧全局方法使用在线间距，旧仅碰撞版本又使用不同来源权重，不能把跨轮差异只归因于物理分量。该对照属于后续机制定型，当前320项和原准入不重写。

正式方法冻结前，优先核对最接近的层次GP与RGPE比较。对它们采用碰撞分类或固定候选选例改编时，明确记录似然、权重、选例规则及原算法差异；项目中的FSBO也按碰撞发现任务的实现说明。最终比较集合、开发选参与成本在独立目标运行前冻结。

## 与正在运行实验的衔接

该核查最初在320项物理分量实验运行时建立。该实验现已全部完成并独立审计，指定主方法`physical_global`相对当时最强参考的漏检减少为35.685464%，没有通过50%门槛；辅助`physical_local`虽为已完成方法中的最高召回98.585721%，没有替换为本轮主方法或改写失败结论。

当前进行[残差尺度历史学习后的240项验证](collision_discovery_residual_scale.md)，预定主方法为`residual_local`。强参考为原22项完成方法加本轮两个目标控制，50%漏检减少门槛、数量、谱系及机制要求在查询前固定。按目前已完成的最高参考，需要达到99.292861%平均召回；新目标控制若更强，按同一规则计算。全部结果与独立审计完成前不宣布阶段B通过，也不进入C/D/E。

## 最接近方法的比较准备

2022年推论1对应SHGP的先验平均。BHGP平均的是目标后验，公式及训练方式不同，不能给`μ_s、K_t+C_s`直接冠以BHGP名称。2024年ScaML-GP给出多来源先验：

\[
m(x)=\sum_s a_s\mu_s(x),\qquad
K(x,x')=K_t(x,x')+\sum_s a_s^2 C_s(x,x').
\]

它是单个潜在GP，不能用`Σ_s w_s P_s(C=1)`代替。原论文的理论允许实权重；实验限制权重为正，并采用独立Gamma(1,1)先验。碰撞分类改编须明确Bernoulli/Laplace推断、潜在尺度、目标均值、优化设置及与原高斯回归的差异。[ScaML-GP定理1与附录C.6](https://proceedings.mlr.press/v238/tighineanu24a/tighineanu24a.pdf)

RGPE已完成[独立碰撞分类实现](../methods/baselines/rgpe/README.md)，包括原文排序投票、目标优先同分、95%分位剪枝与固定核下重新拟合的留一分类后验，并提供有无0.10物理概率分量两种模式。15项数学、隔离与设备检查通过。其二元标签同类对排除、512个独立样本、共享FSBO表示及碰撞概率贪心均作为本项目改编公开，未表述为原样复现。该模块不导入主方法的来源混合器，不修改已有冻结GP实现。

RGPE完整比较复用相同8个历史来源、4个开发系统、两个场景、512候选、8次共同初始化和128次预算；两个模式各40项，共80项。历史来源只由允许的档案构建，目标监督仍只有已付费碰撞。[独立入口与协议](collision_discovery_rgpe.md)先通过68项相关回归、32组历史完整候选概率及1,728个留一后验核对，待原240项验收后冻结，再完成80项运行及240次独立全候选重建。两种分类改编的平均召回为95.1715%和96.4368%，均低于最强参考98.5857%。未中途改写旧参考集合，完整结果进入后续登记比较；97次失败尝试及恢复成本另列，不能把内部消融当作外部基线结果。

这些比较在独立目标及最终方法冻结前补齐；所有完成的强参考进入后续预登记的比较集合。局部可靠性、常见GP迁移、GP集成和ENS均作为已有构造，研究主张仍由机制对照及未参与设计的独立目标结果支撑。

ScaML-GP的[分类设置与历史准备](collision_discovery_scaml.md)使用非归一化来源系数，以平方系数组合协方差；系数保留正值及Gamma(1,1)先验，残差核按二元似然优化。共享FSBO表示及目标截距在标量优化期间固定，历史均值中心化、分类似然与原连续尺度先验的差异均公开。历史检查发现旧固定10步模式在新的标量搜索范围中振荡，已保存失败并采用独立的新收敛求解器，旧冻结文件未改。初始13项专门及81项合并回归、32组完整库概率/目标值/梯度核对通过，不将数值修正单独归因为来源机制。

随后补齐相同推断及核优化的两个无来源目标控制，额外32组历史数值检查通过；四模式17项专门及98项相关合并回归通过。160项独立比较在前序验收后冻结执行，现已全部通过480次独立全候选重建。两种来源版本平均召回90.5785%和94.4997%，对应目标控制为88.3990%和93.7603%，均未超过既有最强参考98.5857%；来源相对目标控制的召回差区间均跨零。全部34种完成方法的汇总及完整曲线另经独立核对。该结果不指定新的本文主方法，[收敛来源条件推断比较](collision_discovery_converged_inference.md)已在该强参考下冻结并开始实际首轮，局部机制仍待完整矩阵检验。

## 保留历史表示与在线策略组合的边界

固定付费状态的[核几何诊断](../results/benchmark/collision/discovery/converged_search/diagnosis/geometry/report.md)发现，冻结原碰撞表示能改善部分IDM/MPC晚期遗漏排序，却损害PPO共同遗漏；冻结安全响应表示没有一致胜出。因此下一项可检验的问题是历史表示应在何处保留、何处适配，而不是将某个冻结核直接宣布为更优方法。该证据只来自已付费状态，尚不是在线收益。

在线选择或混合已有策略本身已有充分先例。[GP-Hedge](https://mwhoffman.com/papers/hoffman_2011.pdf)以在线组合管理多个采集函数；[Active Learning by Learning](https://ojs.aaai.org/index.php/AAAI/article/view/9597)根据策略表现自适应组合主动学习策略；其专家建议背景可追溯至[The Nonstochastic Multiarmed Bandit Problem](https://epubs.siam.org/doi/10.1137/S0097539701398375)。因此“将来源或核视为专家”“以收益更新策略权重”不单独作为原创贡献，也不直接继承这些论文对不同动作、反馈及收益设置的理论保证。

后续若研究选择性保留与适配，应先在历史任务比较适配核、冻结核、固定各半混合和可学习组合，使用严格查询前评分及同信息控制，再冻结完整在线矩阵。核几何、来源身份和组合规则的独立收益须分别验证；沿用开发遗漏坐标指定专家或直接套用旧可靠性权重都不能提供这一证据。

上述收敛来源160项现已完整验收，指定局部主方法召回98.195405%，最强参考仍为98.585721%，50%漏检减少门槛未通过。随后[历史核保留/适配筛选](../results/benchmark/collision/discovery/geometry_retention/report.md)覆盖16任务、640项评分并独立核对，查询前联合来源/视图可靠性在两个场景均未超过预定控制，按约定结束该分支，不增加在线矩阵。固定状态的排序变化没有转化为该机制的完整收益证据，不能据此宣称新增贡献。

[概率百分位诊断](collision_discovery_rank_diagnosis.md)也未改善固定状态发现排序，因此未增加在线重加权变体。[历史树模型筛选](collision_discovery_tree_screening.md)改为检验逐来源响应表达：48项隔离回放中，逐来源特征相对单一汇总响应，历史谱系等权召回提高2.094700个百分点，数量及AUC增加，四个谱系改善，预定历史条件通过。它只含一个种子且与来源训练坐标重合，下一步先检验来源坐标交叉拟合；未达到新的开发准入或独立目标验证。

树分类器、特征拼接及从树分区构造核均作为已有工具，不单独构成原创性主张；树模型黑盒优化见[SMAC](https://www.cs.ubc.ca/~hutter/papers/10-TR-SMAC.pdf)，分区核见[Davies与Ghahramani](https://mlg.eng.cam.ac.uk/pub/pdf/DavGha14a.pdf)。后续方法若保留逐来源表达，仍需证实其超越普通目标代理、单一历史先验和常见特征堆叠的独立收益，再据相同预算的新对象结果收紧研究贡献。

该方向的来源坐标交叉拟合现已完整核查：逐来源版召回77.340510%，汇总版77.173698%，但前者的数量及AUC下降，预登记筛选未通过。先前坐标重合历史结果仍保留，不能用它宣称未见坐标上的独立机制收益。碰撞概率特征分支按约定结束，不新增开发矩阵；来源训练样本量也由512变为409/410，不能把全部变化单独归因于坐标复用。[完整对照及限制](collision_discovery_tree_screening.md)已记录。

后续[全候选预算诊断](collision_discovery_budget_lookahead.md)固定收敛预测模型，枚举16个历史状态中的全部虚拟分支。局部剩余预算ENS相对贪心的实际固定批量潜力平均增加0.125个，两场景均不下降；5步没有实际改善。这里的ENS仍是已有的一次反馈后批量近似，该结果也只是历史状态线索，未建立完整在线方法或来源机制的独立收益。

针对预测概率场漂移的附加计分在预定局部64步条件下因切出退步失败，未纳入后续建议，不将较好的全局辅助结果改成主方法。完整方法如继续比较，必须同步给无来源和同信息控制加入前瞻，并保留共享协方差消融；独立目标、核机制与预算选择的贡献分别由匹配实验决定。当前仅有待确认的阶段顺序调整建议，不将旧阶段B失败改写为通过。

用户最新意见已将优先研究问题收紧为历史后验与目标反馈互补，当前执行依据转向[匹配证据路线](collision_discovery_research_focus.md)，上述400项前瞻建议后置。核心比较区分“共同历史表示”和“显式逐系统后验”，并分别关闭后验输入与目标反馈更新；局部、协方差和前瞻各自由消融决定是否保留。新全局控制须匹配全局可靠性，不能把原局部双目标控制当成严格全局消融。最终主张仍由独立系统结果支撑，新的研究措辞不改变既有失败结论或构成创新性证明。
