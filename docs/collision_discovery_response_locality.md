# 历史响应距离：局部可靠性的历史诊断

## 研究问题与边界

现有局部权重在归一化场景参数空间中传播已付费反馈。残差尺度实验的局部主配置已在40项配对开发任务中低于同尺度全局版本；这组失败结论保留。下一项先诊断：参数相近的场景，是否不如历史系统响应相近的场景适合共享来源可靠性。

本项只读取已有8个历史系统在切入、切出中的档案、历史来源后验和已核对的适配缓存，不新增开发选例、物理调用或轨迹权限。正在运行的240项残差实验及排队的RGPE、ScaML-GP比较保持原配置与准入规则。响应距离、局部核及可靠性混合不单独作为原创贡献。

## 固定方法

历史系统依次作为伪目标，自身从来源后验及距离坐标中排除，保留另外7个来源。基础教师曾使用全部历史对象，本项属于历史参数诊断，不能称为严格留系统或留家族验证。

用固定历史来源后验的边际碰撞概率组成响应坐标，记为`r(x)=[q_1(x),…,q_7(x)]`。这些概率在收到伪目标标签前计算，不随其适配变化。比较

\[
d_\lambda^2(x,x')=(1-\lambda)\operatorname{mean}_j(x_j-x'_j)^2
+\lambda\operatorname{mean}_s(q_s(x)-q_s(x'))^2.
\]

固定`λ=0、0.5、1`；每类距离只比较带宽`0.15、0.30、0.60`，另设`κ=1`的全局控制，共10项配置。高斯影响函数为`exp[-d²/(2ℓ²)]`。来源先验、目标独立质量、外层0.10物理分量、历史选定β、10步目标适配和碰撞监督均沿用残差协议。只改变可靠性证据在候选之间的传播距离。

## 数据、指标与规模

复用种子1301生成的每历史任务128点有序支持集及不相交32点查询集。查询集只用于历史诊断评分，不进入可靠性更新或目标拟合。缓存129个目标模型状态；每次可靠性得分取该标签查询前的分量预测，禁止用拟合该标签后的概率重新评分。

在支持规模8、16、32、64、128评分NLL与Brier，共`16历史任务×10配置×5规模=800`项评分。先在谱系内平均，再对谱系等权平均，两个场景分别汇总。每类距离按NLL、Brier、较大带宽的顺序选择一个设置，完整保留10项及全局控制。

另做留一历史谱系的带宽选择：每个距离仅用其他谱系选带宽，在留出谱系的32点查询集评分。这里只排除了带宽选择中的该谱系，教师仍然见过全部历史对象；结果不能替代正式严格留家族实验。

若响应或混合距离在该带宽选择检查中未同时改善平均NLL、保持Brier不增，并在至少两个历史谱系降低NLL，不仅凭本诊断启动新的开发搜索。即使满足，也只支持下一项候选机制的登记；发现收益仍须在128次预算下对全部届时完成的强参考满足50%漏检减少、数量不降低及两个谱系正收益，并配齐参数距离和全局机制控制。

## 执行与验收

入口为`python -B -m benchmark.discovery_response_locality prepare`和`run`，分别登记诊断与执行评分。输出位于`results/benchmark/collision/discovery/response_locality/`；不写入旧历史缓存、选参证据或在线结果。

必须核对：自身来源与查询标签隔离；参数距离端点与原可靠性更新一致；来源排列不改变距离或预测；影响矩阵对称、自影响为1；全局控制一致；原历史缓存和协议未改变。16任务各在0、8、64、128支持点独立重建全部160候选的分量概率，共64组；每项评分再用独立NumPy矩阵重建权重和混合概率，共800组。数值检查、时间和错误原样保留，预测损失不写成碰撞发现收益。C/D/E状态保持。

## 已完成结果与决定

18项相关检查通过，诊断已完成；64组独立分量概率最大差3.65e-12，800组权重和混合概率最大差分别9.33e-15、1.50e-15。参数距离0.30及全局控制的160项评分与旧登记结果一致，最大差1.00e-15。运行耗时24.99秒，没有新增开发查询或物理调用。

| 切入 | 0.236135 | 0.234950 | 0.233847 | 0.233578 |
| 切出 | 0.159076 | 0.159253 | 0.161018 | 0.158991 |

前三列采用留一历史谱系选择带宽，末列为无需选带宽的全局控制。切入的响应距离在6个历史谱系降低NLL、Brier略降，但全局控制仍更好；切出的纯响应距离在8个谱系均未降低NLL。该证据不支持仅凭替换距离启动新的开发搜索，也不支持把参数距离视为当前局部机制失败的充分解释。完整评分、带宽及数值核对见[结果](../results/benchmark/collision/discovery/response_locality/report.md)。当前240项与后续两个外部基线比较继续按原登记执行。
