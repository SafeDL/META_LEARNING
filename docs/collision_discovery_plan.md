## 1. 研究目标与评价口径

研究目标是：**在固定测试预算下发现更多真实碰撞场景，并提高对候选库全部碰撞场景的召回率。** 不要求新系统一定出现历史系统没有的缺陷。新系统特有失效与失效行为类别覆盖保留为辅助分析。

核心假设是：不同历史系统的测试经验具有局部互补性；少量目标反馈能够识别这些经验的适用区域，从而使碰撞搜索优于全局来源选择及从零学习。

设候选库为 \(\mathcal X\)，执行到预算 \(B\) 时查询过的候选为 \(\mathcal Q_B\)，真实碰撞标签为 \(Y(x)\)，现有参数去重键为 \(d(x)\)。定义：

\[
\mathcal F_B=\{d(x):x\in\mathcal Q_B,\ Y(x)=1\},\qquad
\mathcal F_{\mathrm{pool}}=\{d(x):x\in\mathcal X,\ Y(x)=1\},
\]

\[
N_B=|\mathcal F_B|,\qquad
R_B=\frac{|\mathcal F_B|}{|\mathcal F_{\mathrm{pool}}|}.
\]

同一去重组只要包含真实碰撞，就进入全库碰撞集合；查询该组中的安全坐标并不等于发现该碰撞组。去重场景数不解释为独立软件缺陷数。

| 指标 | 用途与规则 |
|---|---|
| 128 次查询的去重碰撞数、碰撞场景召回率 | 主要评价指标 |
| 16、32、64 次查询的数量与召回率 | 说明低预算表现 |
| 完整发现曲线及 AUC | 说明是否更早找到碰撞；AUC 沿用各次查询后累计发现数的平均值 |
| 对象、接触方向、主车动作、事件阶段的行为覆盖 | 辅助解释发现的失效表现，不作为首轮选例奖励 |
| 新系统相对参考系统的特有碰撞 | 辅助分析，不作为主要学习目标或阶段准入条件 |
| 历史建设、模型训练、适配、选例、实际执行成本 | 分项报告；回放查询与新增物理调用分别计数 |

全库没有碰撞时，碰撞数记为零，召回率保存为 `null`，报告中显示“不适用”。这些任务保留在数量、成本与零失效任务统计中，不将其召回率填成零或一。

在同一候选库内，数量与召回率具有确定比例关系，不将它们解释为两份独立证据。数量汇总包含全部任务；召回率汇总只使用分母为正的任务，并报告有效任务数和谱系数。各方法使用完全相同的有效任务集合。

先在同一实现或训练谱系内汇总，再对谱系等权汇总。方法比较采用配对分层自助法，保留相同系统、场景、环境和选例种子的对应关系；沿用 2,000 次重采样和随机种子 1501。五个选例种子是谱系内重复，不作为五个独立驾驶系统。

**全库标签、召回率分母和未查询轨迹只存在于评估端。** 选择器仅获得候选参数、允许使用的历史信息及已付费查询反馈。有限候选库召回率不外推为连续场景空间中全部失效的覆盖率。

## 2. 既有基础与研究边界

现有工程提供 8 个历史系统、4 个开发系统、8 个既有目标系统，四类功能场景，以及隔离查询、执行账本、轨迹保存、去重和谱系统计流程。主要实现见[方法说明](../methods/gcrt/README.md)、[实验说明](../benchmark/README.md)及[系统注册表](../controllers/highway/catalog.py)。

已有切入档案中的双向失效差异为局部互补性提供了研究线索。例如，在同一批 512 个历史坐标上，IDM 碰撞而 FVDM 通过的场景有 33 个，反向有 43 个。这只能说明失效集合互不包含；阶段 A 仍需验证差异的空间结构、事件阶段及可迁移性，不能据此直接认定局部模型有效。

当前主方法先汇总历史响应关联核，再由多个历史分量共享，来源权重在整项任务中全局更新；在线更新使用实际碰撞 Boolean。首轮固定同一个历史编码器，仅改变来源关联核和来源可靠性权重，隔离两者的作用。间距、碰撞时间 TTC 的历史辅助训练保持一致；事件时延只用于分析，暂不进入在线反馈。

跨系统迁移、状态相关来源选择、局部风险修正和预算感知前瞻已有直接先例。参考 [AAAI 2021 跨任务安全验证迁移](https://arxiv.org/abs/2012.05336)、[ENS 主动搜索](https://proceedings.mlr.press/v70/jiang17d.html)和[配对系统的覆盖感知主动评估](https://arxiv.org/abs/2608.13719)。局部门控或 ENS 公式不单独作为原创贡献；后续研究主张必须由机制对照及独立目标上的发现收益支持。

### 3.3 阶段 B 的开发门槛

强基线集合固定为：无历史 GP、最近来源加残差、Pooled-FT、FSBO。按开发集平均召回率选出其中最强者；依次用平均碰撞数、发现 AUC 作为同分判据，仍相同则按方法标识排序。

“来源独立核＋局部权重＋贪心”原型需要同时满足：

1. 相对最强基线，平均召回率至少提高 **5 个百分点**。
2. 相对同一基线，平均碰撞发现数不降低。
3. 至少两个存在碰撞的开发谱系获得正的平均召回率收益；先在谱系内对有效场景和选例种子汇总。
4. 相对“来源独立核＋全局权重＋贪心”，平均召回率严格提高，平均碰撞数不降低。

以上均使用相同任务、128 次查询及相同有效召回率集合。门槛是研发投入规则，不是统计显著性定义；置信区间仍如实报告。未通过时结束本轮扩大投入，保存诊断与原型结果，不自动增加网络、改变目标对象或启动阶段 D、E。

## 4. 最小方法定义与对照矩阵

### 4.1 来源独立核

令现有冻结编码器对来源 \(s\) 的响应编码为 \(\phi_s(x)\)，每个历史分量使用：

\[
K_s(x,x')=K_{\mathrm{physical}}(x,x')
+\alpha\,\phi_s(x)^\top\phi_s(x').
\]

沿用既有编码维度、归一化、尺度和数值稳定项，不在首轮同时增大模型。历史分量的先验均值继续来自现有历史预测器。独立目标分量保留物理核、零潜在先验均值及 0.25 初始权重。

共享核消融沿用现有来源加权汇总；独立核版本保留各来源关联。两者使用相同冻结编码器和已付费标签，初始家族均衡权重一致。

### 4.2 局部来源权重

来源 \(s\) 在候选 \(x\) 的可靠性定义为：

\[
w_{s,t}(x)\propto\pi_s\exp\!\left[
\sum_{i<t}\kappa_\ell(x,x_i)
\log P_s(y_i\mid\mathcal D_{i-1})\right],
\]

\[
\kappa_\ell(x,x_i)=\exp\!\left[
-\frac{d^{-1}\sum_{j=1}^{d}(x_j-x_{i,j})^2}{2\ell^2}
\right].
\]

其中 \(x\) 使用现有归一化场景参数和类别特征，\(d\) 为特征维数；\(\pi_s\) 是初始来源权重。所有分量，包括独立目标分量，都参与相同的可靠性更新。

每次查询必须先保存各分量对真实标签的查询前对数似然，再更新分量后验。不使用已拟合该标签后的预测重新评分。历史对数似然保持原值，候选位置只决定这些证据在局部权重中的作用大小。全局对照设 \(\kappa=1\)，其更新应与既有全局乘积似然权重一致。

最终碰撞概率为各分量后验碰撞概率的局部加权平均。该定义是待验证的可靠性加权模型，不预先宣称其具有概率校准或无偏保证。

带宽只在开发集比较 `0.15、0.30、0.60`。先以来源独立核局部原型的平均召回率选取，依次以碰撞数、发现 AUC 作为同分判据，仍相同取较大带宽。共享核局部消融使用相同选中带宽，以隔离核结构的贡献。最终带宽在正式评估前冻结。

### 4.3 阶段 B：11 个方法

| 方法 | 核与权重/选择规则 | 用途 |
|---|---|---|
| 随机选择 | 现有随机实现 | 基础发现水平 |
| 历史危险排序 | 现有静态排序 | 直接复用历史的效果 |
| 无历史 GP | 现有目标反馈 GP | 从零学习对照 |
| 最近来源加残差 | 现有来源选择与残差适配 | 简单迁移对照 |
| Pooled-FT | 混合历史预训练后目标微调 | 强适配对照 |
| FSBO | 现有少样本深核适配 | 强迁移对照 |
| 原完整方法 | 共享核、全局权重、五步窗口 | 当前方法参照 |
| 原方法贪心 | 共享核、全局权重、贪心 | 核与权重的共同参照 |
| 来源独立核＋全局权重＋贪心 | 仅改变核 | 独立关联结构贡献 |
| 共享核＋局部权重＋贪心 | 仅改变权重 | 局部适用性贡献 |
| 来源独立核＋局部权重＋贪心 | 同时改变核与权重 | 待验证原型 |

主矩阵为 `4 个开发对象 × 2 类场景 × 5 个选例种子 × 11 个方法 = 440 项运行`，等效付费查询数为 56,320。带宽试验独立记录：只对最后一个原型遍历三档带宽，选中带宽的 40 项运行复用于主矩阵，额外产生 80 项开发运行。因此完整阶段 B 最多为 520 项回放运行、66,560 次等效付费查询，不将调参开销隐藏在 440 项主矩阵之外。

所有方法获得相同候选、初始化、允许的历史信息和已查询反馈。首轮均只用碰撞标签进行在线适配；任何后续连续反馈实验都必须另行匹配信息条件。基线保持各自现有适配机制，不因原型失败而削弱 FSBO 或 Pooled-FT 的适配能力。

### 4.4 阶段 C：选例机制

对来源独立核的全局、局部两个版本，分别增加 `h=5` 与 `h=剩余预算`，共 `4 × 40 = 160` 项运行、20,480 次等效付费查询。对应贪心结果直接复用阶段 B。

选例使用一次虚拟反馈后的未来批量收益近似：

\[
a_h(x)=p_t(x)+\sum_{y\in\{0,1\}}P_t(y\mid x)
\sum_{j=1}^{h-1}p^{x,y}_{t,(j)}.
\]

未来排序排除已查询候选和当前候选。五步窗口取 `h=min(5, 剩余预算)`；完整预算版本取 `h=剩余预算`，其中剩余预算包括即将执行的这一次查询。预算最后一步退化为贪心。这里没有展开完整多步决策树。

局部版本的虚拟更新必须同时处理各分量后验与新证据对各候选来源权重的影响，不得修改真实后验、已存证据或付费账本。

前瞻版本只有在相对相同后验的贪心策略，平均发现 AUC 严格提高、最终平均碰撞数及召回率均不降低时才可保留。满足条件的版本以 AUC 最大者为最终选择器；同分依次取最终召回率高、平均选例时间短者。都不满足时保留贪心。

报告每种选择器的实际计算时间，并同时保留全局权重前瞻对照，检验收益是否仅来自扩大窗口。

## 5. 场景扩展与独立目标

### 5.1 新增交互任务

阶段 D 新增 `cut_in_interaction`，包含切入后匀速、邻道开放与受限两个条件。每个 512 候选库中开放、受限各 256 个，共用一项 128 次查询预算，不按条件分别运行搜索。

- 两个条件共享既有切入参数范围，通过类别特征区分。
- 受限条件在切入方向另一侧车道布置前后背景车，保留纵向制动选项；不强迫主车换道。
- 初始几何、背景运动和事件时序使用与目标身份无关的统一检查；不根据目标是否碰撞筛选坐标。
- 切入后独立制动、侵入预判模块、连续生成和更换仿真平台不进入本轮扩展。
- 新任务重新采集历史与开发响应，训练对应模型；不得直接套用旧场景权重并称为已训练的新任务模型。

新场景单独登记、单独冻结。四类旧场景的定义、采样种子、已冻结配置与历史结果保持原样。新增背景车的具体几何与速度属于阶段 D 的开发配置，须通过轨迹和物理可行性检查后写入冻结清单，在接触新目标结果前确定。

| Beam | 期望速度 29 m/s；深度 4；宽度 16 |
| PPO | 独立训练种子 5107；沿用现有训练协议、交互预算和资格检查 |
| DQN | 独立训练种子 5113；沿用现有训练协议、交互预算和资格检查 |

所有新对象先通过正常跟车、可避免制动、完整停车、合法换道、邻道后车约束五项基本能力检查。资格失败时暂停正式阶段并记录原因，不依据碰撞发现结果替换对象。新配置属于跨系统验证，不自动称为具有开发因果关系的软件版本更新链。

### 5.3 最终模型与冻结

独立验证前，从历史档案重新训练最终模型，使训练时的来源核和权重更新机制与最终推断一致。元训练支持集规模使用 `8、16、32、64、128`；独立开发系统负责模型选择。阶段 B 使用的冻结编码器原型只用于隔离机制，不直接替代最终一致性训练。

严格留家族时，该家族从历史上下文、表示训练、先验和开发选参中同时排除；带宽和选择器也须由允许的开发对象确定。最终目标身份、参数、训练种子和未查询输出不作为选择器输入。

阶段 E 包含四类旧场景与新增交互任务、8 个新目标、5 个配对选例种子，每项仍为 512 候选与 128 次查询。本轮正式条件采用同分布新坐标；新任务的历史、开发、资格和正式坐标在阶段 D 分离并冻结。既有历史坐标复用和困难组合结果保留在旧实验中，不计入本轮正式矩阵。

正式方法集合保留阶段 B 的 11 个方法，将其中完整局部原型替换为一致性重训后的模型；若阶段 C 保留前瞻，另保留同后验贪心以隔离选择器收益。该集合分别运行全来源和严格留家族条件。按保留 11 个方法计算，正式矩阵为 `8 × 5 × 5 × 11 × 2 = 4,400` 项运行；保留前瞻后增加其贪心对照时为 4,800 项。完整矩阵及实际方法标识在阶段 D 冻结，不计入首轮 2,048 次物理补采额度。

最终报告同时列出建库物理调用、等效付费查询、模型建设和在线计算成本。所有任务、零发现运行及未达到预期的结果均保留。

### 6.2 命令入口

以下是**待实现入口约定**。当前仓库尚无 `benchmark.discovery` 模块，不能将这些命令当作已经可以运行的现有功能。入口使用阶段名称，细节读取固定配置：

| 阶段命令 | 前置条件 | 必需输出 |
|---|---|---|

## 7. 验收标准与交付顺序

### 7.1 正确性与公平性检查

- [ ] 全库分母覆盖全部候选的真实碰撞；覆盖零碰撞、全部碰撞、重复参数组及组内安全/碰撞混合的情况。
- [ ] 数量、召回曲线单调不减，召回率在 `[0,1]` 内；零分母以 `null` 保存并在统计中显式处理。
- [ ] 选择器无法读取全库标签、召回率分母及未查询轨迹；只在评估侧汇总这些信息。
- [ ] 局部权重归一化，`κ=1` 与全局规则一致；同步排列来源、先验和证据不改变预测。
- [ ] 对数似然来自查询前预测，真实标签只进入一次后验更新；目标独立分量遵守相同规则。
- [ ] 来源核形状合法、对称且数值稳定；虚拟更新不改变真实均值、协方差、权重证据和账本。
- [ ] 五步、剩余预算和最后一步的窗口边界正确；不重复选择已查询候选。
- [ ] 初始化计入预算，各方法使用相同候选、环境、初始化与选例种子。
- [ ] 正式目标不参与模型选择；留出家族不进入历史、先验或开发选参。
- [ ] 新场景的几何、背景运动、事件时序、主车动作与碰撞对象可由保存轨迹复核。
- [ ] 旧冻结合同、模型与结果完整保留；新实验使用自己的合同和清单。
- [ ] 相关回归检查通过后才启动阶段实验，实验失败记录与重试成本完整保留。

### 7.2 每阶段完成定义

阶段完成要求包括可复核的配置、运行索引、结果和成本记录；运行数必须与冻结矩阵一致。阶段门槛不得依据既有最终目标或新正式目标结果修改。所有门槛结果区分“通过”“未通过”“数据不足/执行未完成”，不把未完成运行当作零收益混入比较。

阶段 A、B 完成后，首先判断局部互补经验是否实际改善数量与召回率。阶段 C 再判断前瞻是否值得额外计算。只有通过前述门槛才投入新增场景、独立目标训练和正式矩阵。若收益只来自更大窗口、单个系统或某一类事件阶段，应按完整对照结果解释，不据此宣称所有机制均有效。
