# 历史后验与目标反馈：开发阶段方法定型

最终采用历史后验的均值与边际方差、全局查询前可靠性和贪心选例。完整来源协方差、局部权重及前瞻不进入当前方法。

协方差控制保持均值、边际方差、初始化、目标与物理核适配及反馈权限相同。按事先固定的规则，主要指标数量与召回均不降低且至少一项提高时选择对角版本；AUC仅用于主要指标完全相同时破同分。本次对角版本平均发现37.700个碰撞组、召回0.983041，完整协方差为37.575、0.981500；AUC分别为24.049219、24.063672。差异较小，区间和完整配对记录保留在[协方差控制](../covariance/decision.json)中。

## 扩大条件与复核

沿用原六项参考（含Indago），最强参考为ScenarioFuzz，平均召回0.872937。对角版本剩余漏检减少86.65%，数量不降低，IDM/MOBIL、线性MPC、PPO三个开发谱系正收益，固定扩大门槛通过。原阶段B报告和旧失败门槛均保留原样。

完整协方差40次重放与B逐次一致，最大误差9.72e-16；对角版本40项与匹配H0F1的40项均通过独立选例核查。两个F0单元共80项通过完整边际预测和全部128次选点等价复用。新增实验为80项、10,240次等效查询；完整协方差验证重放5,120次，CPU设备验证256次，均未新增物理执行。

原始汇总、交互量、全部区间和复用证明见[finalization.json](finalization.json)。扩展后，归档329份源码已实际复核B/C记录，见[源码重放核查](../source_replay_check.json)。最终构建按方案从允许历史重新训练，独立目标结果不用于模型或方案选择。
