# SDC-Scissor 自适应逻辑回归

SDC-Scissor 从执行前可获取的特征预测用例是否失效。Birchler 等在固定候选池实验中考察找到给定数量失效的执行成本，在实时实验中将新执行的标签加入训练集并重新拟合模型。固定套件适配版将上述监督分类和逐次更新用于碰撞优先复测。[原论文，第 4.2、5.2–5.3 节](https://doi.org/10.1007/s10664-023-10286-y) · [按风险选例的固定池实验](https://doi.org/10.1016/j.scico.2023.102926) · [作者工具](https://github.com/christianbirchler-org/sdc-scissor)

| 实现 | 原论文环节与本项目设置 |
|---|---|
| `parameter_features` | 采用范围归一化的四个公开交通参数及适用时的左右方向，代替道路几何特征，标签为原生碰撞。与 DETOUR 共用特征提取。 |
| `fit_classifier` | 合并本场景准入的逐条历史和已付费的当前反馈。在每次拟合时以种子 0 对少数类有放回采样，与多数类等量。使用 scikit-learn L2 逻辑回归，C=1，lbfgs，容差 0.0001，最多 100 次迭代。 |
| `select` | 原实时实验以随机生成的 60 个用例启动并在线过滤候选。本比较使用共同的前 20 次查询及准入历史，在固定池内逐次执行最高碰撞概率的未测点，然后纳入其反馈重新拟合。同分取索引最小者。只有一类训练标签时所有候选同分。 |

入口为 `python -B -m experiments.regression.run_fixed replay --method sdc_scissor --workers 4`。分类器读取场景参数和碰撞标签。每次选择的查询前概率、拟合耗时和实测反馈保存在该版本的付费序列中。分类器设置、软件版本和历史指纹随回放登记。[实现](method.py) · [运行协议](../../../docs/experiment_plan.md)
