# DETOUR 场景参数适配

来源为 [DETOUR 官方实现](https://github.com/cetinkaya/detour/tree/0fae55027d5c13a1452561d82416efda6037f315)。`core.py` 合并了固定提交中的官方检索树节点辅助函数与 `DETOUR` 核心类，算法逻辑与原件一致，许可证见 `LICENSE`。作者以路形作为用例、驶离道路作为失效，提供选择和排序两种模式。本项目使用排序模式，记为 DETOUR 适配版。[工具论文](https://doi.org/10.1016/j.scico.2026.103490) · [ICST 工具赛论文](https://doi.org/10.1109/ICST62969.2025.10988989)

分层聚类对应 `ParameterClusterer.cluster`，使用作者默认的欧氏距离和 Ward 连接。风险分支选择、失败邻近与多样性排序调用官方 `DETOUR.prioritize`，内部种子为 0。`parameter_features` 将道路几何特征替换为按声明范围归一化的四个物理参数及适用场景的左右类别 0/1，碰撞作为失效判据。排序输入为公开候选、准入历史记录的碰撞标签和共同初始化的实际碰撞标签。

同坐标前代记录保留时间上最近的执行结果。固定套件回归在共同 20 次初始化后一次排序全部未查候选，按该顺序逐条支付查询并接受评价端停止信号。官方检索需要至少一条已知碰撞记录，缺少时记录该任务的失败条件。

运行入口由 `experiments` 中的 PPO 回归实验统一调用。数值 GP、模型训练和策略修复不属于该基线。
