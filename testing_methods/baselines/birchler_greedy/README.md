# Birchler 等的黑盒贪心排序

黑盒贪心按到已选用例的平均欧氏距离除以执行成本挑选下一点，对应论文第 3.4 节中作者用于比较的贪心算法。论文的主方法是单目标和多目标 SDC-Prioritizer，原实证用路形特征经 PCA 后的分量及仿真时间。固定套件改用低维公开物理参数和适用时的左右类别，保留总体 z-score 标准化和全部输入维度。共同的 20 次查询替代原论文基于全库距离的单点初始化，所有用例采用单位查询成本，因而最大化距离之和等价于最大化平均距离／成本。并列候选按索引升序排列后用种子 0 抽取。[论文第 3.4、5.1 节](https://arxiv.org/html/2107.09614) · [作者复现包](https://zenodo.org/records/5771017)

`method.prioritize` 生成共同初始化之后的完整静态顺序。它只接收候选坐标和已选索引。统一入口为 `python -B -m experiments.regression.run_fixed replay`。
