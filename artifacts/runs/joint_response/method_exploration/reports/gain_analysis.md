# 共享与独立潜过程的收益分析

读取已完成的32个旧平台任务，初始化20、预算200、种子11。新增付费查询、物理执行及模型更新均为0。本报告为设计资料上的事后诊断，保留全部任务，不改变算法配置或稿件。

规则、优化及搜索控制器合计净增81，两个旧学习控制器净增6；收益并非只来自旧PPO/DQN，但这些仍是旧平台开发对象，不能替代公开ADS验证。
完整候选库合计失效率为9.00%，新流程已付费查询的失效率为34.98%；后者由风险选例主动富集，两者均不能作为自然道路事故率。旧学习控制器的完整库失效率高于其他家族，这仍是核验公开ADS、参数依据及执行语义的理由，不能通过降低采样难度掩盖。

查询q首次发现的失效对AUC贡献为(B-q+1)/B。两种方法的AUC差可精确拆成共同发现的时间变化、新增发现的贡献和未保留发现的损失。32任务的平均差为：

+0.484375 + +7.102969 -6.225469 = +1.361875。

切出任务中共同发现的时间项为负，收益主要来自更换发现集合；换道任务中共同发现更早的时间项抵消了集合替换的AUC损失。数量和速度应分别解释。

全真值失效对数5041，真值加权覆盖率由42.69%变为44.42%。零失效任务6个，覆盖率仍未定义。

`gain_tasks.csv`还列出保留实际初始化后的评估端oracle上界。它仅用于解释预算及真值上限，不作为可访问未查询真值的测试基线。`gain_parameters.csv`给出任务内各集合的参数分位数，仅作事后区域描述；不将新增集合计数当作多样性。
固定实际初始化后的总发现上限为2667，原流程与新流程各有10个非零失效任务达到自身数量上限；达到上限的任务并不相同。

共同Random前缀的排名诊断与自适应选例轨迹不同。前200名中的真实失效数衡量局部排名，NLL/Brier衡量概率预测，两者方向不必相同。固定新模型的RSS条件化在部分前缀改善排名，整体预测损失仍较差；不能据此推断RSS完全无信息，也不能声称RSS已经提高发现效率。

Top200变化为八ADS求和，预测损失变化为八ADS平均。去掉RSS条件化时固定的是已经联合拟合的状态，未去除RSS对历史训练及参数适配的影响，因此不构成从头去RSS的独立消融。

切出目标核的离线先验共享载荷a=-0.02012、潜函数点相关系数约-0.01189，RSS共享潜过程方差占比a²约0.0405%；碰撞独立长度尺度约0.124，RSS独立长度尺度约0.680。弱共享及不同平滑尺度与减少辅助响应干扰的解释相符，但这些是模型潜函数参数，不是观测碰撞与RSS的相关系数或经验解释方差。结构、尺度及梯度分组尚未单独隔离。

已知本次碰撞之后RSS的额外价值应面向未查询候选的碰撞判断。固定且正确的联合概率模型下，额外RSS带来的期望联合对数评分改进等于条件互信息I(Y_U;R_x|Y_x,D_t)。当前模型失配、RSS压缩和近似推断均可能使实际收益为负；已有排名快照不等于对该互信息的估计。

逐查询权重只由此前碰撞预测似然更新。以原始参数分量之外的来源先验π_s为起点，其组内权重满足w_(t+1,s)∝π_s∏_(i≤t)P_(i,s)(y_i)。这给出标准专家混合的逐序列证据恒等式，不是本文新定理，也不保证另一选例策略下的失效数量或覆盖率。
复核6400条实际查询，似然下限触发0次，最大权重误差1.34e-14，组内证据恒等式误差1.14e-13。
在完全相同的已实现序列和已存分量预测上，动态权重累计NLL为1599.59076，固定初始权重为1671.39790，差为-71.80714。该评分诊断不重跑选例，不等于新结构的固定权重策略对照，也不继承旧结构消融的因果结论。

现有同发现数距离结果仍以`e2/reports/paired_differences.csv`为准，未显示一致多样性提升。本次分解解释发现集合与顺序如何变化，不单独识别潜过程结构、尺度和梯度分组各自的因果作用。

方法定位与最近邻文献的核对见[文献记录](../literature_review.md)。异质多输出GP及少样本测试已有先例；本文贡献须由跨ADS来源后验、目标适配及有限预算发现证据支撑。
