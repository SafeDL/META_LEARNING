# 历史迁移与持续收益学习：实验结果

车辆切入和前车紧急制动分别建模。36条完整轨迹检验场景选择，停止与维护效果在预定的留出控制器上评价；全量测试作为成本对照。发现数按控制器等权平均，表中覆盖率为宏平均 Recall；合并计数覆盖率在详细报告中另列。

## 完整预算的发现能力：六种被测驾驶控制器

| 功能场景 | 场景测试集 | 原 LRT：H200 / Recall | 新方法：H200 / Recall |
|---|---|---:|---:|
| 车辆切入 | 前两个场景测试集 | 121.33 / 88.70% | 123.17 / 88.52% |
| 车辆切入 | 第三个场景测试集 | 117.83 / 87.12% | 120.00 / 87.20% |
| 前车紧急制动 | 前两个场景测试集 | 49.00 / 87.45% | 48.83 / 87.07% |
| 前车紧急制动 | 第三个场景测试集 | 48.67 / 86.48% | 48.67 / 86.48% |

## 提前停止：同一组留出控制器

这里仅比较 IDM、IDM＋MOBIL，固定预算与停止结果使用完全相同的任务。这组控制器的覆盖率不能直接与上表六种控制器的平均数比较。

| 功能场景 | 查询数：固定→停止 | 发现数：固定→停止 | 宏平均 Recall：固定→停止 | 合并发现数保留比例 |
|---|---:|---:|---:|---:|
| 车辆切入 | 200 → 192.67 | 114.67 → 111.50 | 97.76% → 95.02% | 97.24% |
| 前车紧急制动 | 200 → 159.67 | 100.67 → 96.17 | 62.88% → 62.29% | 95.53% |

| 功能场景 | 相对固定200次节省 | 相对全量1024次节省 | 该成本情景的宏平均 Recall | 全体任务95%保留验收 |

经验校准结果用于检验实际收益；严格校准使用独立控制器块计数，当前两个校准块不提供非平凡的95%概率早停阈值。
