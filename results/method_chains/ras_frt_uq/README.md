# RAS-FRT-UQ 实验数据

本目录统一存放主方法 **RAS-FRT-UQ** 的 A、D 数据与九方法比较结果；原版 RAS-FRT 保留为对比方法。

结果目录已从 `ras_frt/` 迁移为 `ras_frt_uq/`，活动代码从本目录读取数据并保存结果。冻结协议和源码快照中的旧路径记录生成时的位置；历史模型按文件名从本目录的 `historical_idm/models/` 加载。

当前实验只使用两个场景库：

- [历史库 A](historical_idm/README.md)：2,048 个 S01 场景，每个场景都有同一 IDM 模型的五组参数响应及冻结的历史响应模型。
- [候选库 D](s01_uniform_fvdm_speed_23_mps/README.md)：另 2,048 个 S01 均匀采样场景及目标速度为 23 m/s 的固定 FVDM 响应。目录名直接记录场景与控制器条件，论文中称为 D。

D 中 116 个场景发生自车碰撞（5.66%）。主比较为同一 D 上的九方法、200 次可见标签回放；早期 100 次比较和融合开发记录保留在同一个 D 目录以核对协议来源。全库 2,048 条 FVDM 响应用于事后评价，选择器在回放中只获得已查询标签。融合方法在查看 D 结果后确定设置，因此 D 上比较属于开发阶段证据。
