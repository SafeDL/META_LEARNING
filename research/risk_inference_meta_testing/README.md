## 待检验机制

学习风险响应及其不确定度，直接改善弱风险反馈后的失效推断，而不只在固定后验上重新拟合碰撞读出。

使用历史 SUT 作为任务，支持输入仅为 `(x,R)`，未查询碰撞作为元监督。历史已知行为参数可以用于风险模型监督，目标真实参数不进入选择器。

拟采用一个共享潜在高斯场的响应模型：

\[
G_s\sim\mathrm{GP}(0,k),\qquad
R_s(x)=\operatorname{clip}\{\mu_R(x,z_s)+a_R(x,z_s)G_s(x)
+\nu_R(x,z_s)\epsilon_R,0,1\},
\]

\[
C_s(x)=\mathbf1\{\mu_C(x,z_s)+b_fG_s(x)+\epsilon_C>0\}.
\]

其中两种 epsilon 为独立标准正态工作误差，z 是历史已知、目标未知的行为描述，f 是场景族。风险均值采用无输出 sigmoid 的神经头，潜在分数允许超过边界，观测仍为原定义的 [0,1] 风险；两个正幅度头学习相关误差与独立工作误差。协方差 `diag(a) K diag(a) + diag(nu²)` 保持正定。C 使用 probit 事件模型，在高斯条件后验下具有解析均值；风险边界观测仍需明确说明矩投影近似。

首版实现使用原冻结风险预测作为均值偏置，加上无输出压缩的神经修正，故潜在均值并不受 [0,1] 限制。特征归一化仅使用训练配置。风险模型与碰撞模型共用潜在场；风险边界采用高斯尾概率，碰撞采用 probit 条件均值。

共享潜变量、正定协方差构造及 probit GP 本身都是已有技术。待验证贡献是风险均值／似然参数经由风险支持集到未来失效损失的训练，能否恢复现有高风险查询中的有效响应差异。实现通过不等于已经取得优势。

## 实验范围

- 复用同一 highway-env 物理库；GPU Python 环境仍为 metadrive。
- 控制器、场景、初始设置、风险公式、碰撞判据、池及 200 次唯一查询预算保持一致。
- 沿用已公开数据的 24 训练／12 验证／12 开发留出划分，不称独立盲测。
- 固定风险特征骨干，学习风险均值与幅度头、碰撞头；普通监督与元推断模型使用同结构、同初始化、同可用历史标签与相同优化预算。
- 本阶段只用贪心选例；与前阶段普通监督贪心及七个冻结参照作工程比较，与同结构普通监督模型作机制归因。

## 阶段预算与验收

第一阶段只用种子 11、23，各方式固定 1,000 步，含相同的风险模型初始化。验证使用相同风险上下文，并检查实际完整池预算边界的碰撞排名，不再只使用易饱和的 256 场景子集命中率。

先验证混合风险密度／边界概率、正定协方差、批量与在线条件化、梯度、风险输入隔离及训练／部署读出一致性。验证阶段必须改善历史危险查询上下文下的未查询失效预测与排序；均匀上下文的预测改善不足以晋级。

若固定验证支持机制，再锁定完整训练预算与五种子开发回放；否则阶段总结并结束本设计，不追加结构或超参数网格。两项共同主指标仍为发现面积和终点召回。后续独立确认只在开发证据成立后使用新配置、新坐标和预注册检验，不因开发结果改变成功标准。

实现情况：首版模型、可微后验及训练入口已实现；10 项数值检查及真实历史风险支持集的 GPU 梯度检查通过，两种子验证已结束。150 支持观测的梯度检查包含 9 个上边界风险，峰值显存约 8.85 GB。前阶段结论见 `../risk_feedback_meta_testing/results/development_stage.md`。

入口：`python -B -m research.risk_inference_meta_testing.test_method`、`python -B -m research.risk_inference_meta_testing.train`。训练总步数 1,000，其中共享风险初始化 200 步，其余 800 步分别进行普通监督与元推断训练；两个模式架构、初始化、数据与优化预算相同。

普通监督在历史已知行为和单点已查询风险下学习碰撞；元模式只用风险支持集构造未知行为后验，再预测未查询碰撞。两者额外使用同一批历史查询风险作风险似然校准监督，该标签不进入元模式的适配上下文。损失是两项平均负对数似然之和，梯度范数上限为 10。

检查点按验证配置中 10/50 次历史策略风险查询后的未查询碰撞 log loss 选择。完整池静态延续排名另作机制门槛，不能将其当作真实后续逐次查询的 F200。模型、验证记录与实现检查均保存在本目录 `results/`。
