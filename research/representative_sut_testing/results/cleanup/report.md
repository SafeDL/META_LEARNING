# 本轮代码与实验产物清理

本轮收敛活动代码，不启动新实验。按 `docs/style.md` 删除退役源码、失败方法的可执行分支、过期开发配置与入口，将已冻结实验记录完整归档。保留方法的实验指标没有改变。

## 保留主链

- `evaluate_student_risk.py`：恢复 Student-t 阶段的原排程与发现计数保护；数值计算沿用该阶段冻结实现。
- `evaluate_feedback_correction.py`：全局在线可信度、历史数值 EP、仅事件符号模型、联合发现损失与参照保护。数值 EP 保留为必要控制。
- `evaluation.py`、`feedback_audit.py`：从退役入口提取指标、反馈披露和实际账本核查，避免主链继续依赖旧收益学习模块。
- `baselines.py`、`summarize.py`：保留 14 个冻结基线；汇总入口仅重算基线，历史方法比较仍作为冻结结果保存。

清理后的执行结果写入新目录，避免覆盖旧源码快照。SUT ID、历史目录名与已冻结日志字段保留原名；新增模块使用职责名称。每个目录仍只保留一个 README。

## 清理范围

原有 88 个 Python 文件中，删除 61 个退役源码与测试文件，新增或提取 6 个职责明确的文件，活动目录现有 33 个 Python 文件。

退役内容包括历史收益学习、旧前瞻、响应通道扩展、未获收益的独立二元核、风险顺序约束、自适应证据共享，以及它们的开发、诊断与汇总入口。持续平均保留，十次初始化后固定解释的分支删除；仅事件符号模型保留，安全风险排序分支删除；实际二元损失支持保留，未调用的严格倾向排序支持删除。

54 个旧实验目录及失败的风险顺序子分支退出展开目录，共归档后移除 2387 个结果文件、484 个空目录。原展开结果约 446.67 MiB，完整归档约 65.65 MiB，净减少约 381.02 MiB。
