# 联合响应模型与风险反馈下的失效发现

## 研究问题与当前选择

历史系统在相同场景上的风险和真实碰撞响应存在差异。我们要研究的是：新目标少量连续风险反馈，怎样改变未查询场景的真实失效排序，并同时改善早期发现与预算内最终召回。

当前确认候选采用历史任务学习的联合 GP 和直接后验失效概率选点。来源身份混合、排序辨识筛选与前瞻积分均已做开发对照，尚无稳定的双指标优势，未进入锁定候选。不能用这些未采用的模块解释当前结果。

## 历史坐标与联合随机函数

令六个来源预测风险为 r_j(x)，预测碰撞概率为 p_j(x)。取 eps=1e-4：

```text
z_R,j(x) = logit(clip(r_j(x),eps,1-eps))
z_C,j(x) = Phi^(-1)(clip(p_j(x),eps,1-eps))
m_R = mean_j(z_R,j)
m_C = mean_j(z_C,j) + offset_family
B_R,j = (z_R,j-mean_j(z_R,j))/sqrt(M-1)
B_C,j = (z_C,j-mean_j(z_C,j))/sqrt(M-1)
```

两个场景族拥有独立的来源响应对比系数。下式的 B 已按场景族扩展为独立列块；失效均值偏置不进入中心化对比：

```text
z_R(x) = m_R(x) + sqrt(eta) B_R(x) u + d_R(x)
z_C(x) = m_C(x) + sqrt(eta) B_C(x) u + a(x)d_R(x) + d_C(x)
u ~ N(0,I)
d_R ~ GP(0,sigma_R^2 K)
d_C ~ GP(0,sigma_C^2 K)
```

u、d_R、d_C 在先验中独立。K 在不同场景族之间为零，族内由 0.9 倍历史风险响应距离的 Matérn-5/2 核和 0.1 倍四维归一化物理距离核组成。前者长度由历史任务学习，后者长度为 0.2。

局部加载函数为 a(x)=softplus(theta_family^T h(x))。h 的六项是常数、历史风险坐标均值与标准差、历史失效潜在坐标均值与标准差、经验风险—失效响应灵敏度。该灵敏度是跨来源协方差除以风险方差与正则之和，不是驾驶物理的因果导数。

softplus 约束共同局部差异的方向。来源对比的交叉协方差仍可有正有负，因此该约束不意味着任何风险增加都会使所有候选的失效概率增加。

## 联合核与条件更新

记 A=diag(a)。上述生成结构直接给出半正定联合核：

```text
K_RR = eta B_R B_R^T + sigma_R^2 K
K_CR = eta B_C B_R^T + A sigma_R^2 K
K_CC = eta B_C B_C^T + A sigma_R^2 K A + sigma_C^2 K
```

目标反馈只有 y_R=logit(clip(真实风险))，使用高斯工作观测方差 tau^2。代码选项 noise 存的是方差，不能误读为标准差。它表示响应模型误差与正则，确定性模拟器并未被假定有随机测量噪声。

每次查询 x 后进行标准联合高斯条件更新：

```text
den = K_RR(x,x) + tau^2
mu_C' = mu_C + K_CR(:,x)/den * (y_R-mu_R(x))
K_CC' = K_CC - K_CR(:,x) K_CR(:,x)^T/den
```

风险均值、风险协方差、交叉协方差和 u 后验同步更新。没有把风险阈值当作真实碰撞，没有风险到碰撞的第二条校准伪观测，也没有两条输出按预算插值。

## 为什么可以从 GP 读出失效概率

当前模型定义 C|z_C ~ Bernoulli(Phi(z_C))。因此，若 z_C|D_R ~ N(mu_C,v_C)，则：

```text
q(x) = E[Phi(z_C(x)) | D_R]
     = Phi(mu_C(x)/sqrt(1+v_C(x)))
```

Phi 是标准正态分布函数。GP 的均值和方差描述潜在函数后验；q 才是该工作模型下的失效概率。概率链接是生成模型的一部分，不是任意在风险 GP 外面套 sigmoid。历史网络的 sigmoid 输出、风险的 logit 坐标与此处的 probit 链接承担不同职责。

这仍是可检验的工作模型；物理碰撞概率是否校准以及跨参数组合是否有效，要用独立实验判断。

## 固定 w 的替代与解释边界

初始经验均值为六个历史响应坐标的等权平均，u 初始均值为零。这是明确的历史先验，等权不表示六个系统对新目标同样适用。目标风险反馈随后改变 u 的均值、协方差和局部 GP 差异。

在一个场景族中，来源部分可以写成有效函数系数：

```text
w_j = 1/M + sqrt(eta/(M-1)) [E(u_j|D_R)-mean_j(E(u_j|D_R))]
sum_j(w_j) = 1
```

这些系数随查询变化，可以为负，作用于 logit 风险或 probit 失效潜在坐标，且完整模型还含局部差异。它们不构成非负来源混合概率，不能解释为目标属于某个控制器的概率，也不能直接当作物理风险概率的加权平均。

来源之间的危险排序相似时，单纯辨识来源不会自动改善选例。组件对照应检验来源对比是否额外减少遗漏，而不是只展示系数变动。

开发阶段进一步检验了初始均值本身。仅学习失效均值的方案令每族 gamma_C=softmax(theta_C)，以历史任务的条件失效排序监督估计 gamma_C；风险参考仍取经验均值。失效初始均值为 gamma_C 加权的历史 probit 潜在响应加族偏置，核与局部加载保持原值。因此目标反馈后的有效失效系数为 gamma_C 加上上述来源对比的后验修正。经验协方差基底仍围绕经验来源均值中心化，改变参考函数不改变联合核的有效性。

另一个对照同时学习风险与失效均值，并添加 0.1 倍风险上下文 Mahalanobis 损失。该配置在部分池上增加遗漏；它与仅学习失效均值的配置同时改变了风险均值参数和辅助损失，不能单独归因于其中一项。当前独立确认仍使用此前锁定的经验均值候选，学习失效均值的优势目前只在开发数据上成立。

## 风险反馈能辨识什么

对潜在失效差值 z_C(i)-z_C(j)，一次查询 x 减少的条件方差为：

```text
[K_CR(i,x)-K_CR(j,x)]^2 / [K_RR(x,x)+tau^2]
```

两候选具有相同风险交叉协方差时，该查询不能辨识它们的潜在分数差值。查询点自身方差大，不能单独说明其有排序价值。这是标准高斯条件化在本模型中的直接推论。

更强的边界来自完整无噪声风险函数这一理想情形：

```text
z_C = m_C + A(z_R-m_R) + sqrt(eta)(B_C-A B_R)u + d_C
Cov(z_C|z_R) =
  eta (B_C-A B_R) Cov(u|z_R) (B_C-A B_R)^T + sigma_C^2 K
```

即使知道全部候选风险，来源响应系数与风险局部差异仍可能混淆，且独立失效差异 d_C 无法由风险直接辨识。只有历史支持的共同结构能够被风险反馈迁移；风险观测不能保证还原全部碰撞。该协方差恒等式已与直接 Schur 补条件化核对，不应包装成新的通用 GP 定理。

还需区分响应系数 u 与失效迁移参数。给定已查询位置，风险观测的边缘似然为：

```text
p(D_R | X_R) = N(y_R; m_R(X_R), K_RR(X_R,X_R)+tau^2 I)
```

当前 m_R 和 K_RR 不含初始失效均值系数 gamma_C、风险—失效加载 a、失效偏置或独立失效幅度 sigma_C。因此仅凭目标风险似然无法辨识这些参数；要依靠历史真实碰撞的离线监督。u 与风险过程共享，仍可被风险反馈条件化，并通过历史学到的交叉结构修正失效预测。在线响应系数更新与离线迁移关系学习是两件事，不能把前者写成“在线学会全部来源适用性”。查询位置由算法自身选择，其采样偏好也不能作为额外的目标身份观测。

## 决策目标与未采用的探索模块

定义 F_t 为前 t 次查询发现的真实失效数。参考效用为：

```text
J = 0.5 F_B + 0.5 mean(F_1,...,F_B)
```

第 s 次查询的真实失效贡献为 0.5+0.5(B-s+1)/B，后期发现仍有明确收益。在只考虑本次收益的决策中，该权重对所有候选相同，因此最大化 q(x) 同时最大化本次的两个指标期望增量。当前方法采用这个直接规则；这不证明整段闭环最优。

开发阶段另外比较了高斯—Hermite 积分的一次观测前瞻、相邻排序差值的方差减少筛选，以及全局或按场景族的来源身份混合后验。它们未稳定改善两个指标，所以没有保留在当前确认候选中。风险 QDScore 仅为附加评价。

## 学习、确认与贡献范围

历史任务监督学习核幅度、响应距离长度、工作观测方差、局部加载系数和失效均值偏置。真实历史风险构成上下文，真实历史碰撞构成未进入上下文的离线排序监督。六个历史任务均用于元训练；整组留出仅约束历史预测器训练，不能称为独立元测试。

原始目标池、此前确认数据和四个完整开发池用于选择方法。独立确认另取 24 个新 IDM/FVDM 参数组合，每个两个新 Sobol 池，每池 2048 候选。制动能力范围 3.5–9 m/s²、期望间距 6.5–9.5 m、感知延迟 0.025–0.5 s。完整测量用来知道真实失效总数，选择器只能看到自己已查询的风险。

确认以参数组合为统计单位，两个指标分别比较三个主要对照，六项精确双侧配对符号翻转检验使用 Holm 校正。本轮 alpha=0.025；相对此前最佳还要求两个配对 bootstrap 95% 区间下界均为正。符号翻转依赖零假设下配对差值符号可交换；参数组合只来自已声明的范围和同一仿真器。

联合 GP、概率链接、贝叶斯适配与主动搜索已有基础工作。候选贡献是把历史风险—失效响应差异组织成可被风险反馈更新的共同结构，并用不可辨识边界说明何时这种迁移有用。性能优势和研究新颖性需要各自的证据，不能互相替代。

## 对理论与创新不足的具体处理

首先把三种量区分清楚：历史任务学到的初始参考系数、目标反馈后的响应系数、目标自身的局部差异。原来的机制组固定权重没有目标适用性的学习依据，不能继续用“均衡”解释其最优性。当前在线后验解决响应系数始终不变的问题；下一候选学习初始失效均值，检验初始化是否也应由下游失效发现任务决定。学习系数仍然定义先验，不能用“不是手工设置”推导为对任意目标适用。

训练目标围绕已知风险上下文之后的未测真实碰撞排序。与仅回归总体风险相比，该目标直接监督我们需要迁移的风险—失效关系。它仍需与等权先验、历史任务学习的固定排序、只做局部适配和完整在线适配比较，才能判断哪些结构值得保留。

理论首先服务于解释：联合核的半正定性、条件更新、概率读出和风险反馈不能消除的失效差异均给出明确模型与数值核验。这些是工作模型的性质。不能把标准高斯条件化换一个名称，也不能从模型内可辨识性推出物理系统中保证找到全部失效。

相关工作的边界需要明确。异质多输出 GP 已经联合处理具有不同似然的输出，并使用共享潜在过程构造协方差，见 [Heterogeneous Multi-output Gaussian Process Prediction](https://proceedings.neurips.cc/paper/2018/hash/165a59f7cf3b5c4396ba65953d679f17-Abstract.html)。因此，“连续风险与二值失效联合建模”本身不作为独立的新理论贡献。

剩余预算驱动的非短视发现也已有系统研究，见 [Efficient Nonmyopic Active Search](https://proceedings.mlr.press/v70/jiang17d.html)；利用便宜代理帮助发现昂贵真实目标已有 [Nonmyopic Multifidelity Active Search](https://arxiv.org/abs/2106.06356)。这些结果进一步要求我们把候选研究定位落实到历史系统响应差异、只使用目标风险反馈时能够迁移的失效结构，以及相同预算下的实际发现增益。当前直接后验排序不声称新的非短视最优策略。

下一轮只在完整确认结束后选择方案。若本轮未通过，保留锁定记录，将该队列明确转为开发数据；在它上面验证学习初始均值或进一步学习迁移关系，再锁定新方法，用新参数组合和新坐标检验。两个主要指标分别验收，固定排序仍作为必要的机制对照。新颖性判断和独立性能判断各自成立，任何一项都不由另一项自动代替。

## 当前开发：学习两种响应之间的映射

第一轮未通过后，进一步检验相同来源系数同时解释风险与失效是否过强。将来源项改为：

```text
z_R = m_R + sqrt(eta) B_R u + d_R
z_C = m_C + sqrt(eta) B_C T_f u + a(x)d_R + d_C
```

T_f 是每个场景族的历史响应对比映射，不是来源身份概率或 attention 权重。对应源交叉协方差为 eta B_C T_f B_R^T，源失效协方差为 eta B_C T_f T_f^T B_C^T。对任何实矩阵 T_f，联合核由共享潜在变量生成，仍为半正定；T_f=I 恢复原来源关系。风险边缘过程保持不变，失效初始均值系数另外用 softmax 学习。

固定初始均值与局部参数后，目标风险反馈更新 u，再通过学到的 T_f 迁移失效响应。处于 B_C T_f 零空间的来源变化不会产生源失效变化，因此该映射能够检验哪些风险响应差异值得迁移。它仍是多输出 GP 的一种来源结构，不能把增加矩阵本身称为新的通用理论。

开发队列按控制器类型分别取八个训练、四个验证参数组合，共十六训练、八验证；每组合两个坐标池。预测器种子 11 用于训练，原始冻结来源预测器不变。只学习初始均值的对照与同时学习映射的方案使用相同元任务、反馈规模、监督和训练步数；风险先验、局部加载、各局部方差及工作观测方差固定。400、800、1200 步检查点仅在这次开发中选择。验证队列也来自已经失败的第一轮，不能作为新的独立确认。

单位映射恢复原模型、任意映射的联合协方差半正定性、整组排除梯度隔离、顺序风险更新与批量条件化的一致性已通过四项测试。在线候选仍只使用已查询风险，因此该尝试不依赖真实碰撞反馈的新增权限。

八个检查点与组件配置共 640 次留出开发运行已经完成。相同失效均值下，增加映射改善最终召回，却降低发现面积；该结果没有证明映射在两个主要指标上都必要。因此暂不将它定为最终主链。

## 当前开发：让训练反映预算内的失效发现

历史碰撞与安全用例的普通成对排序监督，没有区分预算内与预算外的排序错误。进一步开发使用冻结行为策略在十六个训练目标上的真实风险查询轨迹，分别截取 0、10、30、60、100、160 次后的上下文；两个池、两个来源网络种子共 384 个上下文。行为策略仅看到自己查询的风险，未使用目标碰撞选点。训练监督来自训练目标的完整碰撞库；八个验证参数组合的标签不进入参数拟合。

已执行 t 次后，剩余预算 b=B-t。若剩余候选暂按一个固定顺序执行，处于剩余位置 k 的真实失效对双指标平均效用的贡献为：

```text
g_t(k) = [0.5 + 0.5 (b-k+1)/B] 1(k<=b)
```

将一个失效与一个安全用例交换，固定尾部顺序的效用变化绝对值为 |g_t(k_positive)-g_t(k_negative)|。用当前预测排序得到位置，以这个变化加权成对 softplus 损失，再加 0.1 倍总体二值负对数似然。权重对当前排序取值，但不对离散排序求导；它是训练替代损失，不是闭环实际效用的精确梯度，也不证明序贯最优。

这种按指标变化加权的排序学习思想已有 [LambdaRank](https://www.microsoft.com/en-us/research/publication/learning-to-rank-with-non-smooth-cost-functions/)，不能把换用本项目预算效用后的权重称为新的通用排序理论。这里要验证的是，基于目标风险上下文的历史迁移学习，是否需要直接针对有限预算的真实失效排序训练。

三个配置共享初始均值、冻结行为轨迹和元训练随机序列：普通排序仅学习失效均值、预算加权排序仅学习失效均值、预算加权排序同时学习失效均值与局部加载。风险先验、单位来源映射、独立失效方差、观测方差和偏置保持固定。使用稳定的 probit 对数似然计算训练分数；这仅避免损失数值端点，未发现已有排序受概率饱和影响的证据。

由于风险过程不含待学习的失效均值和加载参数，可预先计算给定风险上下文的来源项与局部项条件矩。新的七项测试核验其与联合 GP 直接条件化的一致性、预算贡献与真实排序交换效用的一致性，以及单一类别或极端分数下的有限梯度。在线选择仍直接按后验失效概率排序，且两个主要指标分别验收。

## 风险反馈下的覆盖限制

设两个目标在全部候选上的风险函数完全相同，但真实失效集合不同。只接收风险反馈的算法在两个目标上得到相同的观测记录；给定同一个随机种子，查询集合也相同。若两个失效集合的并集大于预算，算法不能保证在两个目标上都找全。即使两个集合各自不超过预算，这个限制仍成立。

更具体地，若两个目标分别具有 B 个互不相交的失效，则任何 B 次查询对两个目标的发现数之和不超过 B，因此至少一个目标的召回不超过 1/2。随机策略的两个期望发现数之和同样不超过 B。这是观测不可区分性的直接论证，不是新的 GP 定理，也不声称已在当前物理参数族中构造出风险函数逐点相同的两个目标。

这说明，固定权重、学习权重或更复杂预测器都不能单靠风险数据证明完整失效恢复；必须明确额外的历史风险—失效关系假设，并用新的真实目标验证。

## 风险先验估计的开发结论

另在相同十六训练、八验证组合上，用真实风险的高斯工作似然比较学习风险均值与同时学习风险均值和协方差。全程未用碰撞拟合风险边缘参数；失效均值、局部加载和两个正来源增益随后用训练碰撞单独监督。风险基底仍围绕历史经验均值中心化，学习新的风险参考均值不改变该基底。

风险预测的平均负对数密度由 1.89705 改善至 1.65552，但随后的 720 次失效发现验证没有超过已选预算均值方案。学习风险协方差的 800 步方案相对此前最佳面积差为 +0.14427 个百分点，召回差 +0.05549；200、400 步的召回差为负。风险均值学习也未形成双指标优势，因此该分支不进入主链。五个脚本／测试与全部源码、结果共 975 个条目逐文件验证后归档，六项数学检查随分支保留在 `archives/risk_prior_learning.zip`。

## 后续表示：以行为状态条件化响应

上述仿射历史响应迁移之外，新的开发目录为 [behavior_response_testing](../behavior_response_testing/README.md)。利用历史已知行为配置训练 r(x,z) 与 p_C(x,z)，其中 z 包含制动能力、期望间距、感知延迟和控制器类型。新目标的真实 z 不提供给选择器；选择器利用已查询风险推断其后验。

当前工作模型为风险响应网络加零均值场景局部 GP 误差。不同 z 的条件误差协方差相同，已查询位置相同，因此可共享高斯条件更新；根据每个 z 查询前的风险预测似然更新后验。失效概率为：

```text
q_t(x) = sum_z p(z | queried risks) p_C(x,z)
```

p_C 是历史真实碰撞监督的二值网络概率；风险 GP 只定义风险似然与预测误差，不在风险 GP 均值外任意添加 sigmoid。z 跨两个场景族共享，局部风险误差按族独立，因此一次反馈可通过行为后验改变另一场景族的失效排序。该版本暂假设给定 z 后，失效网络响应不再依赖风险预测误差；这项结构也要接受实际发现对照。

初始行为分布来自声明的三项参数范围与平衡控制器类型，仍是一个先验，不声称取消初始化。与固定来源组合不同，网络定义连续行为状态下的非线性响应，目标反馈随后改变该行为分布。贝叶斯校准本身已有基础，研究贡献仍须落实到历史响应表示、风险能够辨识的失效方向及相同信息条件下的实际发现收益。

十六个训练组合的 65536 条响应和历史行为配置是新增训练信息。固定排序、离散历史状态后验，以及此前最佳算法接入相同预测器、十六来源和重新拟合的风险—失效校准，均为必要对照。当前所有这些结果来自已转为开发的第一轮数据；下一轮显著性只能在新的组合与坐标上检验。
