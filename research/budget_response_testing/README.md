# 预算相关训练的目标响应测试

本目录收敛下一候选的活动实现。初始失效均值由历史监督学习，目标连续风险反馈更新来源响应系数和局部差异，再按后验真实失效概率选点。元训练使用冻结测试策略产生的风险上下文，将排序错误按对预算内最终发现及累计发现面积的影响加权。

模型使用 logit 风险坐标和 probit 失效坐标；初始失效均值的 softmax 系数是函数系数，不是目标身份概率。风险经验均值仍是初始参考，不能声称所有初始化都已取消。来源响应的有效系数随目标反馈变化。

仅保留单位来源映射、学习均值与直接概率排序。早期前瞻、来源身份混合、概率校准分支和未形成双指标优势的响应映射不进入本实现。完整训练与组件证据保存在 [开发目录](../response_adaptive_testing/README.md)，第一轮未通过的确认输入继续冻结。

`model.py` 构造联合风险—失效 GP；`session.py` 实现风险反馈条件更新与 200 次查询。两类目标、五个来源网络种子共十次完整运行的 2000 条查询与开发实现逐点一致，反馈顺序检查同时通过，共十一项。

预算训练在八个留出开发组合的面积与召回差分别为 +0.16498、+0.17496 个百分点，但全部 24 个开发组合仅为 +0.03067、+0.09911。当前改善尚不稳定，尚未锁定下一轮独立确认；继续检查风险经验等权初始化与风险先验估计。代码收敛不等于已取得独立显著优势。
