本目录只保存所有方法共用的物理场景、原始响应和执行协议。算法模型、运行记录和比较结果存放在 `results/`。
文件从原RAS-FRT结果目录直接迁移，未重生成或改变scenario_id、坐标、标签及控制器配置。

|---|---|

|`s01_fvdm/`|D：2048个场景、固定23m/s FVDM原始响应、协议及模板|
