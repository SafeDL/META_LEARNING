# 候选库碰撞发现对照

[collision.py](collision.py) 在同一候选库和查询预算下运行以下方法：

| 方法 | 选择依据 |
|---|---|
| 随机 | 随机选择未查询场景 |
| 空间填充 | 优先选择与已测参数点距离较远的场景 |
| 历史危险排序 | 优先选择任一允许历史来源预测危险程度较高的场景 |
| 最近来源＋目标残差 | 先用共同初始化反馈选择一个最相近来源，后续根据目标反馈修正预测 |
| 无历史 GP | 只用已查询的目标标签拟合高斯过程，按碰撞概率选择 |
| Pooled-FT、FSBO | 使用各自预训练模型，根据目标反馈微调后选择 |

各方法只能获得候选参数、允许的历史输入及已查询反馈。共同初始化计入总预算，选例与适配耗时分别记录。执行与报告入口见 [实验运行说明](../../../benchmark/README.md)，场景和指标解释见 [项目说明](../../../README.md)。
