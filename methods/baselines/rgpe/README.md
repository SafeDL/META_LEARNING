# RGPE 碰撞分类改编

本目录实现排序加权高斯过程集成（Ranking-Weighted Gaussian Process Ensemble，RGPE）的碰撞分类版本。依据是[Feurer、Letham、Bakshy 的2018年原始版本](https://arxiv.org/pdf/1802.02219v1)，不是后续同一 arXiv 编号下的修订算法。原论文优化连续响应，本实现用于固定候选库的真实碰撞发现，名称为 `rgpe_classifier`；它不是原论文的原样复现。

## 保留的机制

每个历史来源保留固定的潜在高斯后验，目标GP只适配已查询碰撞。权重来自来源在已查询位置的联合后验样本，以及目标GP的留一预测排序损失。每个留一折重新求解Bernoulli/Laplace潜在后验；目标核、表示与均值保持为全部已查询标签适配后的参数，不在每折重新拟合这些参数。这与原论文固定超参数的留一规则对应。

每个候选来源的损失中位数超过目标损失样本95%分位数时，将其排除。当多个分量损失并列最小时，目标分量参与并列则优先分配给目标；其余并列按均匀随机处理。潜在集成均值为 `Σ w_s μ_s`，方差为 `Σ w_s² v_s`，再积分logistic函数得到碰撞概率。不能用碰撞概率的加权平均替代这个GP集成。[原论文第4节](https://arxiv.org/pdf/1802.02219v1)

## 碰撞任务中的明确改动

- 连续响应GP改为Bernoulli似然与10步Laplace近似；二元标签保持0/1，不作逐任务响应标准化。
- 排序只比较标签不同的有序样本对。同类样本对没有碰撞排序信息，全部排除。未查询或只有一类已查询标签时没有可用排序对，所有损失相同，按目标优先规则使用目标GP。
- 每次采用512个独立高斯蒙特卡洛样本。不同来源及不同留一折独立抽样，同一折内保留所有位置的联合协方差。512是本实现的固定计算设置，不声称是2018年论文已核实的样本数。
- 目标GP使用同一FSBO基础表示，每次从原模型重置，使用已付费碰撞标签适配10步Adam、学习率0.003。这里控制表示与适配信息，不沿用原论文的高斯回归和MCMC超参数推断。
- 在未查询候选中按碰撞概率贪心选点，代替连续优化的期望改进。相差不超过1e-12时按场景标识排序。共同随机初始化计入总预算。
- 抽样使用独立随机生成器，种子为 `sampling_seed + 1009 * 已查询数`。来源按标识排序，输入排列不会改变抽样顺序或选择结果。

另提供 `physical_rgpe_classifier`：在以上潜在GP集成得到碰撞概率后，按0.90/0.10混合独立物理GP的概率，用于控制主方法固定物理分量的影响。该物理GP也只使用已查询碰撞，每次重置并以10步Adam、学习率0.01适配。这是本项目的匹配控制，不是原论文RGPE的组成。

## 接口与验证

入口为 `methods.baselines.rgpe.search.select`，通过现有 `run_isolated` 和 `QueryLedger` 调用。参数包括公开候选、隔离查询接口、FSBO基础模型、历史来源的 `names/means/covariances`、共同 `initial_indices`、`sampling_seed`、模式及预算。来源构建与角色排除由评估端负责，不能给选择器全库目标标签、召回分母或未查询轨迹。返回记录保存每次查询前的权重、剪枝、损失摘要、概率与分别计量的适配时间。

`methods/common/gp_joint.py`支持不同支持集的批量Bernoulli/Laplace预测，供目标留一折使用。已有冻结分类器与运行协议保持原样。

```powershell
python -B -m pytest tests/baselines/test_rgpe_search.py -q
```

15项检查已通过，包括独立SciPy模式优化、批量留一与逐折拟合一致、固定核下排除留出标签、已有分类器退化、GP方差平方权重、相关高斯抽样、原文剪枝与同分规则、单类标签、预算、仅付费标签适配、来源排列、辅助安全量不影响选择、隔离查询及CPU/CUDA一致性。深核包含FP32表示计算，完整库与支持子集的批大小可能产生约1e-9概率差；相应退化检查使用2e-8容差。

随后与新增比较入口及既有组件合跑的68项回归通过。历史核查覆盖全部8个历史伪目标×两个场景×8/128支持点，32组完整512点预测和1,728个留一模式均与独立NumPy/SciPy一致，有限蒙特卡洛权重与剪枝完全相同，最大概率差1.63e-10。每项排除自身来源；教师包含所有历史对象，不作为独立留系统泛化证据。

独立80项开发比较现已完成，10,240条反馈和240次独立全库重建通过。两种分类改编的平均召回率为95.171525%和96.436841%，未超过既有最强参考的98.585721%。结果与97次单列失败前缀均保留，不替换旧主方法或自动通过后续门槛。完整结果、恢复过程、角色和成本见[RGPE开发协议](../../../docs/collision_discovery_rgpe.md)，文献安排见[方法定位](../../../docs/collision_discovery_method_positioning.md)。
