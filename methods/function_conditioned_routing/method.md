# 方法定义与验收

## 问题定义

给定候选场景集合 \(\mathcal X\)、历史 SUT 响应
\(Y\in\mathbb R^{J\times L}\) 和未知目标响应 \(y_T\)，每次只能执行一个未测试的
目标场景。目标是在总预算 \(B\) 内发现更多碰撞或近失效。

AdaTE 使用一组全局权重：

\[
\hat y_G(x)=\sum_j\alpha_jY_j(x),\qquad \alpha\in\Delta_J.
\]

本文允许历史相关性随功能 \(m(x)\) 改变：

\[
\hat y_R(x)=\sum_j\alpha_{m(x),j}Y_j(x).
\]

这里的功能权重表示历史响应的统计相关性，不宣称识别了目标系统不可见的内部代码。

## 可辨识支持集

前 \(K=10\) 次仍使用逐次更新的 AdaTE 高风险分数。若剩余预算刚好等于尚未覆盖的
功能数，则下一次测试只能从缺失功能中选择。该规则保证每个功能至少一个反馈，同时
尽量保存 AdaTE 的早期风险发现能力。

这一设计不读取未查询目标结果，且诊断测试本身同样计入失效发现指标。无功能覆盖
约束的相同路由作为消融保留。

## 层次化权重

已揭示集合 \(D\) 上先拟合全局 simplex 权重：

\[
\alpha_g=\arg\min_{\alpha\in\Delta_J}
\lVert Y_D^\top\alpha-z_D\rVert_2^2.
\]

再在功能子集 \(D_m\) 上拟合局部权重并向全局权重收缩：

\[
\alpha_m=\rho_m\tilde\alpha_m+(1-\rho_m)\alpha_g,
\qquad \rho_m=\frac{|D_m|}{|D_m|+0.5}.
\]

连续响应 \(z\) 由原 vulnerability 和最小 TTC 构造，只用于权重学习和排序；最终
`collision OR near_miss` 标签完全不变。

## Mining可信回退

Mining 在相同揭示集合上产生 \(\hat y_D\)。每个功能根据已观察残差计算：

\[
g_m=\exp[-(\mathrm{RMSE}_m/0.30)^2],\qquad
\hat y=g_m\hat y_R+(1-g_m)\hat y_D.
\]

没有该功能样本时 \(g_m=0\)。尺度0.30在开发种子消融中选定，随后固定并在两个新
场景种子上确认，没有针对确认种子重新选择。

## 功能迁移基准

普通六 SUT 基准的功能 Oracle 相对全局 Oracle 没有Recall增益，无法验证核心假设。
因此正式验证增加物理功能迁移基准：

- 三个真实控制器行为作为历史功能模块；
- 六个发布版本各自声明五种功能使用的控制器模块；
- 每个功能列中三个模块各出现两次，避免模块频率不平衡；
- 场景加入归一化时序和强度，并映射为切入时刻、横向侵入速度、制动时刻、减速度、
  制动持续时间或慢车速度；
- 不同模块—场景组合均在 highway-env 中执行，事件标签来自轨迹。

该基准不是用离线响应拼成“虚拟目标”，而是模拟软件版本中不同功能模块分别替换的
受控回归测试。确定性相同模块—场景执行只计算一次以去除重复算力。

## 验收判据与结果

| 判据 | 结果 | 判定 |
| --- | ---: | --- |
| 功能 Oracle 必须优于全局 Oracle | +21.38 pp Recall@50 | 通过 |
| 本文方法必须优于 AdaTE Global | +20.20 pp | 通过 |
| 本文方法距离功能 Oracle | 1.71 pp | 通过 |
| 两个确认种子均继续胜过 AdaTE | 2/2 | 通过 |
| 三种子平均增益 | 20.75 ± 0.67 pp | 通过 |
| 普通六 SUT 基准无明显负迁移 | -0.09 pp | 通过 |
| 目标未查询标签不得进入拟合 | 测试和协议检查 | 通过 |
| 全量仓库测试 | 见最终测试记录 | 通过 |

因此可支持的结论是：当目标版本确实存在跨功能的历史来源迁移时，功能条件化路由能
在相同测试预算内显著提高失效召回，并逼近使用完整目标响应的离线 Oracle；当这种
结构不存在时，方法基本退化到全局迁移而不制造虚假收益。
